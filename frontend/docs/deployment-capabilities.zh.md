## 云端 Web 边界

云端 Web 保留手工录入持仓、浏览器批量导入、创建备份、经过认证的备份下载、浏览器上传、导入预览、显式导入和清空。备份位置呈现为托管存储，不显示也不能选择服务端目录。

Host 会拒绝目录列举／创建／选择、原生打开路径、自定义会话工作目录、按路径采纳 Workspace、打开设置文档、打开 agent preset 目录，以及本地券商／原生持仓操作。Session 与 Workspace 投影会省略 Host 规范绝对路径。即使调用方绕过 UI，这些服务端检查仍然生效。

备份浏览器协议有明确上限：只能选择配置备份目录下的直接 `.pabackup` 文件；符号链接与非普通文件会被拒绝；传输前验证归档；超过 64 MiB 的文件会被拒绝；文件 I/O 开始前会原子预留容量。打开文件后会再次检查大小，并且只读取该精确字节数，因此并发增长不能扩大内存分配。最多同时常驻两个不可变下载（压缩归档总上限 128 MiB）。并发校验期间可短暂保留这 128 MiB，再加上最多 256 MiB 的有界解压归档内容（逻辑载荷总上限 384 MiB，不含分配器开销）；分块传输前会释放校验载荷。分块必须有序且大小匹配；完成、取消、过期或出错都会释放常驻会话。活动过期计时器会主动删除被遗弃的快照，不依赖后续请求触发清理。

认证仍由 Web auth 提供传输边界。本能力矩阵只收窄部署行为，不扩大认证策略。容器／进程沙箱与服务健康属于后续云端部署工作，不在本次变更内。
