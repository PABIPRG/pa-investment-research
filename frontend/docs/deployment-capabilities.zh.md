## 云端 Web 边界

云端 Web 保留手工录入持仓、浏览器批量导入、创建备份、经过认证的备份下载、浏览器上传、导入预览、显式导入和清空。备份位置呈现为托管存储，不显示也不能选择服务端目录。托管存储始终使用实例拥有的默认目录，并忽略更早本机部署保存的自定义目录，但不会覆盖该设置。

Host 会拒绝目录列举／创建／选择、原生打开路径、自定义会话工作目录、按路径采纳 Workspace、打开设置文档、打开 agent preset 目录，以及本地券商／原生持仓操作。Session 与 Workspace 投影会省略 Host 规范绝对路径。即使调用方绕过 UI，这些服务端检查仍然生效。

备份浏览器协议有明确上限：只能选择当前存储目录下的直接 `.pabackup` 文件；符号链接与非普通文件会被拒绝；传输前验证归档；超过 64 MiB 的文件会被拒绝；文件 I/O 或解压开始前会原子预留容量。最多同时存在两个下载快照和两个预览。上传允许四个并发会话，预留总量为 128 MiB；预览预留也具有 128 MiB 压缩字节总上限。打开文件后会再次检查大小，并且只读取该精确字节数，因此并发增长不能扩大内存分配。分块必须有序且大小匹配。Runtime 释放会关闭共享创建门禁，中止并等待进行中的资源创建，再释放内存、预留和上传临时文件；之后的新建请求会 fail-closed。完成、取消、错误或活动的十五分钟过期计时器会执行同样的局部清理，不依赖后续请求。备份列表诊断保持稳定，绝不包含 Host 原始文件错误或路径。

认证仍由 Web auth 提供传输边界。传输资源尚未关联认证主体，因此注销后 cancel RPC 开始返回 401 时，系统无法同步回收该主体的资源；全局配额和活动的十五分钟计时器会限制剩余存活时间。关闭这项限制需要 Connection／Gateway 请求 Context 把认证 owner 传入 Runtime。容器／进程沙箱与服务健康仍是独立的部署事项。
