# @deepseek-ai/dsh-client-ui-desktop-shortcuts

[English](README.md) | 中文

仅用于 Electron 的桌面快捷键功能。Host 端注册 `ui-desktop-shortcuts` 设置命名空间；Client 端只在可信 preload 能力存在时，向设置面板贡献“快捷键”页面。默认值按当前操作系统动态派生，不会复制进用户数据。

| 操作 | macOS | Windows | Linux |
|---|---|---|---|
| 打开设置 | `Command+,` | `Ctrl+,` | `Ctrl+,` |
| 切换全屏 | `Control+Command+F` | `F11` | `F11` |
| 最小化窗口 | `Command+M` | 由系统管理 | 由系统管理 |

快捷键只在应用内生效：Electron 仅在产品窗口处于前台时匹配。编辑器记录一组基于物理按键的组合键，拒绝未搭配修饰键的输入键、系统保留组合与动作间冲突，然后只写入当前平台的自定义层。用户可以恢复单项默认值，也可以在确认后清除当前平台的全部自定义；其他平台已保存的自定义不会受影响。

## 模型体验

无；桌面快捷键及其设置页不会进入模型请求。

#### KV Cache 影响

无；本包既不组装也不发送 provider 请求。

## 已知限制与延期工作

- **仅前台窗口**——该功能刻意不注册操作系统全局快捷键，应用在后台时不会执行动作。
- **Windows／Linux 没有应用自有的最小化默认键**——这些平台继续以窗口管理器惯例为准；用户仍可录制一个应用内替代键。
- **物理按键范围**——自定义支持字母、数字、常见符号与 `F1`–`F24`；媒体键和布局专有键不会持久化。
