# @deepseek-ai/dsh-client-ui-investment-research

[English](README.md) | 中文

`investment-research` Profile 专用的投研工作台 UI。该包保留正式产品壳的会话、消息、输入、附件、工具、审批和工作区服务，通过 `shell.overlay` 替换业务导航并增加投研工作台页面。

侧栏将八个产品域组织为四组：

- 总览：研究工作台。
- 分析与盯盘：智能分析、实时盯盘。
- 策略闭环：策略研究、影子验证、自进化。
- 个人与图谱：我的投研、产业链。

“研究工作台”是默认入口，集中展示持仓、风险预警、个性化市场事件、策略匹配和当前风险画像，不把业务页面变成另一份对话记录。“实时盯盘”使用 `market-watch` 的市场扫描、技术信号和实时资讯操作；“我的投研”在当前页面读取和编辑持仓、自选、KYC、风险画像、行为画像与组合风险；“产业链”在当前页面完成公司检索、公司档案、五列链路、多层展开、节点档案和网络切片。“策略研究”“影子验证”和“自进化”分别读取策略、影子持仓、净值、就绪状态和业绩归因操作。

各数据区独立加载和失败。先完成的数据立即展示，失败区域保留自己的重试入口，刷新期间保留上次成功值。请求代次会阻止旧筛选对应的晚到响应覆盖当前选择。该保护只作用于浏览器状态，不等于网络取消；当前 Host transport 不接收这些页面传入的 `AbortSignal`。

浏览器不能传入后端地址、端口或任意路径。所有读取和业务写入都使用稳定 operation 名称，由 Host 映射到固定路由并管理后端租约。个股与持仓分析、简报、历史回测、策略假设与入池、策略回测与状态迁移、影子验证和自进化均在各自页面调用后端业务接口；只有结果解释和延伸研究才进入投研助理。

悬浮助理入口和页面内研究动作会在当前业务路由右侧打开正式会话区，不会压缩页面、跳转路由或丢失页面状态。每次入口触发都会通过 Workspace 服务新建独立对话，再向该对话的共享输入框写入结构化业务上下文；不会复用历史会话。模块上下文由页面点击时快照、模块后端快照和精简整体数据组成，明确限制为金融研究，不包含代码或工程研究指令。用户确认后再发送，因此不会绕过模型选择、附件、审批或发送策略。历史对话抽屉继续使用正式 Session 与 Workspace 服务，支持搜索、打开、重命名和归档。

## 模型体验

### 投研工作台

#### 模型看到什么

模型不会在用户仅浏览页面时自动收到数据。触发助理解读后，页面快照、模块后端快照和精简整体数据会组成结构化草稿；只有用户在共享输入框中确认并发送后，才会沿用 `ctx.conversation` 的正式上下文组装路径进入模型请求。

#### Token 影响

浏览、筛选、刷新和运行后端业务任务不消耗模型 token。助理解读动作会预填有界结构化上下文；用户发送后，其 token 影响取决于当前页面快照大小，并与同一会话中的普通消息一起计入。

#### KV Cache 影响

直接数据页面不创建模型请求，因此不影响 KV Cache。用户发送预填提示词后，缓存行为与当前会话中的其他消息一致。

## 已知限制与暂缓事项

- 浏览器对后端响应做容错展示，但不复制后端业务规则。
- Host 或后端错误会保留为可重试的真实数据状态，界面不会替换成虚构结果。
- React 状态可以忽略被新选择取代的响应，但已经发给 Host 的请求仍会运行到结束。
- 统一任务目前通过状态轮询取结果；页面关闭或应用重启后，内存任务需要使用后端返回的任务编号重新查询。
