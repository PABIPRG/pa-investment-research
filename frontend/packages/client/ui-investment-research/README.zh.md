# @deepseek-ai/dsh-client-ui-investment-research

[English](README.md) | 中文

`investment-research` Profile 专用的投研产品 UI。该包保留正式产品壳的会话、消息、输入、附件、工具和审批能力，通过 `shell.overlay` 增加默认研究工作台、顶部搜索、七个业务模块、历史对话抽屉与统一报告中心。研究工作台聚合真实持仓、组合风险、个性化事件、可解释的策略匹配与盘前简报任务，和内部 Workspace 存储抽象不是同一个概念。Workspace 不在侧栏、空白对话流程或产品设置中出现；首次运行且没有已登记 Workspace 时，Profile 会自动创建普通 Host-cwd Session，让用户可直接开始对话。

研究工作台与七个业务入口组成连续的 `1+7` 研究验证链路，均读取真实后端状态，不生成演示数据：

- “研究工作台”是默认首页。持仓、风险、预警、个性化事件与策略匹配区域独立完成加载；持仓金额明确标注为成本金额，不把成本价伪装成实时市场价格。个性化事件使用 `comment: false`，浏览首页不依赖 LLM 凭据。

- “智能分析”复用正式会话与模型工具；“实时盯盘”读取市场扫描、技术信号和基础实时资讯。
- “策略研究”把真实事件转成候选假设并运行样本外回测。打开策略详情只是临时浏览，不会把卡片选为后续工作对象；“AI 评审”和“进入影子验证”等操作会显式携带策略选择。“影子验证”读取纸面账户状态、持仓与净值；“自进化”先展示归因和只读预案，只有用户再次确认才写入策略库。
- “我的投研”读取后端持仓、组合风险和风险预警，支持校验、预览并导入 CSV / TSV 或粘贴表格；“产业链”先检查本机数据状态，首次使用时仅在用户明确确认后下载约 25 MB 的许可数据，完成后从 `industry-chain` 后端读取统计、公司检索与分层上下游链路，并把事件传导单独作为次级参考。下载、检索与链路刷新会显示各自的加载、空、失败及旧数据保留状态。

实时盯盘与我的投研按数据区独立加载，先完成的数据立即展示；单个区域失败时只显示该区域的错误和重试入口。同一请求尚未完成时不会重复发起，同键刷新保留上次成功结果，晚到的旧响应不会覆盖当前筛选。策略回测与影子验证通过任务状态接口等待真实结果，完成后由后端持久化正式报告。

“机会发现”首屏明确请求基础实时资讯，不启用事件富化或个性化排序，因此不会同步等待完整慢来源或最长 60 秒的可选 LLM。后端返回部分来源或 stale cache 时，页面分别显示“部分来源”或“缓存资讯”；完整来源、事件富化与个性化仍保留为 `news-flash` 的显式可选能力。

这里的“忽略晚到响应”只是浏览器状态保护，不是网络取消。当前 Host transport 不接收本页面传入的 `AbortSignal`，被新请求取代的后端调用仍会运行到结束。

浏览器不能传入后端地址、端口或任意路径。所有请求都使用稳定的 operation 名称，由 Host 映射到固定接口并管理后端租约；动态报告、策略和任务标识也由 Host 验证后才进入固定路由。

历史对话抽屉直接使用正式 Session 服务，支持标题和消息内容搜索、打开、重命名和归档；“新对话”会取消未完成的预填并显式清空新会话草稿。页面中的 AI 操作只预填短的工具调用意图，不把业务 JSON 写入输入框；模型在用户确认发送后通过 `investment_context` 或对应分析、盯盘工具读取最新上下文。全局“投研报告”入口统一展示分析、回测和验证任务生成的持久化报告。

## 主题与浮层约束

本包的功能样式只使用 `ui-theme` 提供的 `--dsw-alias-*` 语义 token，不写 React 内联样式、颜色字面量、`--dsw-static-*` 静态色板变量或组件级明暗主题选择器。新增共享颜色时先在 `ui-theme` 定义语义 token，再由本包消费；`pnpm run verify-client-theme-styles` 会扫描本包当前及后续新增的所有 CSS Modules 和 TypeScript 呈现源码，并在 CI 中拒绝违规或不存在的 token。

主题偏好只通过 `ctx.theme` 读取和切换。需要覆盖整个应用的模态浮层通过 React Portal 挂载到 `document.body`，使用应用模态层级和主题遮罩 token，避免被内容容器、顶部栏或侧栏的层叠上下文裁剪。

## Model Experience

### Investment workbench

#### What the model sees

模型不会直接看到页面读取的行情、持仓、策略或报告 JSON。只有用户在共享输入框中确认并发送的短工具意图，才会沿用 `ctx.conversation` 的正式上下文组装路径进入模型请求；模型随后按需调用 `investment_context` 等工具，工具结果会通过正式会话事件进入上下文。

#### Token effect

浏览和刷新业务页面不消耗模型 token。AI 按钮只预填简短意图；用户发送后，提示词与后续工具结果按普通会话规则消耗 token。

#### KV Cache effect

业务页面本身不创建模型请求，因此不影响 KV Cache。用户发送预填提示词后，缓存行为与同一会话中的其他消息一致。

## Known Limitations and Deferred Work

- 页面按后端现有响应做容错展示，没有在浏览器复制策略、影子或进化判定规则。
- Host 返回错误时页面显示可重试的真实错误状态，不回退到交互稿假数据。
- 页面可以忽略被新筛选取代的响应，但尚不能取消已经交给 Host 的后端调用；长任务超出前端等待窗口后仍会继续在后端运行，并可从报告中心查看结果。
