# Public Observatory Host Gateway

公开观察室的免登录只读 Host 网关。它只注册 `/api/public/performance/v1` 下的固定读取路由，以精确 Origin、Host、方法和查询参数白名单约束访问，并通过 `InvestmentPythonRuntime` 读取 trading-core。

生产配置必须显式提供 `allowedOrigins`；空列表时插件不公开任何数据。该包不复用或放宽受保护的 `/api` 路由，也不接受浏览器提供的后端地址或任意路径。

## 发布范围与服务端配置

`DSH_PUBLIC_OBSERVATORY_ORIGIN` 控制 Host 的浏览器来源，例如 `https://pair-observe.xiexin.dev`。CORS 不是账户授权：无 Origin 的公开 GET 也可读取已经批准的数据。

trading-core 只发布 `DSH_PUBLIC_OBSERVATORY_SNAPSHOT_IDS` 中逐个批准的账户快照，值为最多 366 个 32 位小写十六进制内容 ID 的 JSON 数组；默认 `[]`，缺失、损坏或超限均不发布任何记录。每份快照重新校验并计算内容哈希，导入或篡改记录不能借用已批准 ID。新账户快照不会自动公开。日历与曲线每天取最后一份批准快照，盈亏前值也仅来自批准集合；这些快照对应固定系统活动摘要，不发布原始成交或研究正文。

`DSH_PUBLIC_OBSERVATORY_OPERATIONS_SINCE` 独立控制持仓操作的持续公开，默认空（关闭）。启用时填写经批准的起始时间（ISO 8601，必须含时区），只纳入该时间之后开始且已经归档的持仓导入／重置、日常持仓及历史资料更新、成交记录更新；缺少开始时间的旧记录不回填。此许可包含后续操作的固定摘要，以及详情中证券代码、变更前后数量与成本价，包括操作前已有的持仓值；部署者须确认这个公开范围，不能仅理解为“展示操作标题”。成交只公开新增／移除条数，不公开原文、私有编号或券商路径。不自动授权权益快照，也不包含影子策略。

导入／重置成功记录要求 Host 已确认全局提交；独立后端的 `backend_only` 不公开。正常写入记录要求业务 JSON 原子替换成功并完成私有归档；待恢复期间返回不可用，匿名 GET 不执行恢复。回滚记录只说明本地持仓恢复，不声明全局失败或资金恢复。活动的 `occurred_at` 是记录时间（传输归档观察时间或普通写入意图记录时间），页面显示“记录于”，不是实际成交时间；成交资料同步也不意味着此刻新执行了交易。变更字段不能解释为资金进出或盈亏。原始归档、UUID、文件名、备注和账户标识不输出。缺少完整持仓字段时详情返回 `holdings_changes: null`；只有成功重置的明确空文档按清空解释。

内部 `POST /portfolio/account-snapshots` 要求专用 `X-Public-Observatory-Token`，与服务端 `DSH_PUBLIC_OBSERVATORY_WRITE_TOKEN` 常量时间比较；未配置、缺失或错误均返回 403，鉴权在解析请求体和访问存储之前完成。令牌应使用至少 32 字节密码学随机值，仅配置在 Host/后端，绝不能放入 `VITE_*`。managed 后端由 Runtime 显式转发，attached/external 后端由操作者直接配置。接口不是公开网关的一部分，目前没有公开页面写入口或自动生产者。

修改服务端变量后需重启对应 Host/后端。撤销发布必须删除部署白名单中的 ID，不能只删除存储记录；相同内容可能被恢复。响应为 `Cache-Control: no-store`，包括错误和 304；已被访客保存的公开内容无法追溯删除。发布许可不进入账户备份。

同一 `DSH_PUBLIC_OBSERVATORY_OPERATIONS_SINCE` 许可也包含持仓备份生成后的固定摘要，按原始开始时间判断许可；手动导出、导入前备份和重置前备份分别显示。仅接受 Host 已落盘并回读校验的完成回执，不声称浏览器下载成功，不公开备份路径、文件名、哈希或其他分类。此事件不含持仓差异，也不表示资金变化。撤销该变量后旧列表与详情都不可读取；匿名 GET 不补记回执。

## 生命周期和限额

公开读取通过 `getRunningBackend` 获取业务插件已经持有的健康后端地址，不启动进程、不增加 lease 引用、不阻止 owner 停机。后端未运行或读取失败返回脱敏 503，不自动恢复业务。

默认每 IP 每分钟 120 次、每实例总计每分钟 600 次、并发 8 个请求；对应 `requestsPerMinute`、`totalRequestsPerMinute`、`maxConcurrentRequests`。上游整个读取过程与下游发送各受 `timeoutMs` 限制（默认各 5 秒）。`maxResponseBytes` 默认 2 MiB，上限 8 MiB；流式读取在越界时中止。慢客户端在发送结束或超时断开前持续占用并发额度。浏览器取消与插件卸载中止上游读取；浏览器 Cookie/Authorization 不转发，重定向禁止。

账户写入体最多 512 KiB、每快照最多 1000 个持仓；只读账户文档最多 8 MiB，超过或导入中返回不可用，不无限等待存储锁。持仓操作通过业务写入方维护的派生索引查询，GET 不扫描原始归档、不初始化或修复索引；索引缺失、损坏、资源超限或非法发布起始时间返回脱敏 503，不截断后冒称完整。[索引所有者与恢复方式](../../../../backend/dsh-trading-core/README.md#操作查询索引与恢复)。权益范围最多 366 天，活动分页最多 50 条；重复参数、非法日期和未知参数被拒绝。

活动游标固定首屏数据上界，翻页期间新增及回填记录在刷新后才出现；日期、筛选、发布许可与索引代次都绑定在游标内。范围变化或重建使旧游标失效，网关返回脱敏 409 `cursor-expired`，页面清除旧页和旧详情并重读首屏；普通网络错误仍可手动重试。游标不暴露私有编号、归档总数或数据库位置，不能长期存为书签。

## 验证

包内测试覆盖真实 YAML Loader、HTTP 路由隔离、撤销缓存、并发/速率与慢连接。额外设置 `OBSERVATORY_TEST_PYTHON` 为已初始化 trading-core 的 Python 解释器路径后，`tests/loader-composition.spec.ts` 会运行真实 Python 投影的跨层测试；测试只使用自动清理的临时合成账户，不启动业务 lifespan。未设置该变量时此项跳过，不能算作跨层通过。

## Known Limitations and Deferred Work

- 限流为进程内计数，多实例需在部署入口增加统一限流与连接保护；Python 业务端口必须保持内网隔离。
- 显式快照发布是保守的首版方案；自动采集、发布管理 UI 与研究/成交审批不在当前读取能力中。
- 原始归档和导出回执仍需监控磁盘容量；索引或回执异常须通过私有维护恢复，不能让匿名请求扫描原文兜底。
- 大于 8 MiB 的既有 holdings 文档不适合此读取路径；需要后续由账户所有者生成独立的有界发布投影，不能直接放宽至无限读取。
- 现有备份导出包含账户快照，但导入合并未接入 `account_snapshots` 的恢复；不能把备份存在视为已验证可恢复。
- 生产 Host、Vercel、DNS、反向代理和真实账户的部署验收仍需独立授权与验证。

## Model Experience

本插件不向模型提供工具、提示词或上下文，不改变模型 token 或 KV-cache 使用。
