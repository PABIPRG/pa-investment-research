# Vokie 动效学习稿

参考：https://vokie.com/ 。分析日期：2026-09-14。此稿用于理解与验证主导机制，不是投研产品首页，也不是已通过用户验收的完整复刻。

## 本次学到的关键关系

首屏是完整舞台：主体约占视口中部一半宽度与大部分有效高度，标题直接叠在主体中间，说明压到舞台底部。源站桌面截图为 1440×1000，本稿验证为 1280×720；构图可比较，不能称同视口像素对齐。

动效不是统一由滚动控制。源码中的不同驱动必须拆开理解：

| 对象 | 公开源码证据 | 学习稿 | 验证与差异 |
|---|---|---|---|
| 首屏五胶囊点云 | Three.js 自定义 shader；入场聚合 1.9s、延迟 .38s；独立时间循环 | 原创 WebGL 表面采样与真实透视，保留形态和叠字关系 | 实际看到云态与终态；采样、亮度、缓动和循环仍不同 |
| 指针 | 局部屏幕空间排斥，165px 作用半径，位移平滑恢复 | 原创屏幕空间排斥 | 未单独完成指针轨迹对照；本稿无原站的恢复平滑 |
| 首屏滚动 | 滚动只叠加 x / z 旋转，scrub 1 | 滚动叠加姿态 | 未做同进度定量对照；本稿直接跟随，无 GSAP 延迟 |
| 深浅转场 | clip-path 从右边界100%裁切到0，top bottom → top 42%，scrub 1 | 按视口比例连续展开同方向遮罩 | 实际看到中间态及反向收回；跟随延迟不同 |
| 四块能力面板 | 桌面 25% → active40%、其他20%；窄屏纵向 | 保留尺寸关系，使用原创 CSS 视觉 | 展开交互未完成独立浏览器验收；第三四块视觉素材有意不同 |
| 浅色大粒子空间 | 独立 Three 几何点云，时间驱动旋转；100dvh、超近相机 | 原创超大环面点云、深度尺寸变化 | 浏览器看到空间裁切与叠字；相机与采样不同，不冒充相同模型 |
| 文本演示 | tab 切换取消旧动画，逐字输出；支持方向键 | 原创文本与取消逻辑 | 浏览器点击第三项看到打字中间态；快速切换、键盘未验证 |
| 横向过程 | 桌面宽度≥901、高度≥700时 pin；横移=轨道宽−视口宽，scrub1 | 原生 sticky 与滚动映射；窄屏纵向 | 实测 y4047，固定顶部0，横移−989.812px；反向后−521.812px；本稿无 scrub 平滑延迟 |
| 页脚 | 字形切成13条，指针拖拽碎片与短生命周期颗粒 | 当前仅原创整字浮起 | 明确简化，未复现切片效果，不计入保真通过 |
| 结果折叠/全部产品媒体 | 原站还有协调高度动画、SVG与视频生命周期 | 本稿未覆盖 | not tested / 未复现 |

## 来源证据

结合既有采集任务中的首屏、800/2400/4000px 滚动截图进行结构分析。此次原站浏览器操作多次超时，不能把源码分析写成此次已完成的原站全程实测。原站移动端、减少动态和性能仍未知。

## 学习稿验证

- JavaScript 语法检查通过，WebGL 两个画布均成功初始化。
- 浏览器看到入场云态、聚合终态、大粒子空间、遮罩中间态、横向过程与反向位移。
- 桌面 1280×720、手机模拟 390×844 未出现页面横向溢出；手机解除流程固定。
- 页面内“减少动态”按钮实测：粒子静态终态，CSS animation-name 为 none，遮罩解除，流程改纵向。此为本稿替代模式，未验证系统级 prefers-reduced-motion 切换。
- 未测：原站与学习稿同视口同阶段连续录像对比、指针独立对照、全部循环周期、真实手机、FPS/能耗、后台与离屏的运行时性能。
- 当前只能证明主干机制学习稿可运行；参考保真仍有明确差异。不能据此宣称完整复刻或已经具备稳定一次生成的质量。
