# Agent Note: 云端管理员的模型配置权限

Status: proposed

## Problem

PAB-17 / WEB-AUTH-001 的登录边界通过后，模型页面仍依赖仅限有效 loopback 的通用配置接口。直接开放这些接口会扩大到所有 settings 命名空间与任意环境变量引用。

## Proposal

在同一个 ApiProxy 中提供 modelAdmin 操作，复用 settings 与 credentials 的验证、revision、文件持久化和事件通知。HTTP 入口要求现有管理员认证；未启用认证的远程部署不获得该权限。Electron 和本地模型页面仍走原接口。

读取只投影 llm-deepseek 与 llm-pi-ai 的模型编辑字段，各层均排除 headers 和其他字段；提供方 URL 去除账号、查询及片段，凭证只返回 configured/writable。写入只允许提供方层及明确字段，不接受祖先路径、原型键、任意凭证引用或全局配置。新增凭证引用必须由 route 派生，已有引用可保持。模型列表只接受模型 ID、名称、说明和容量字段。

远程发现只支持公网 HTTPS 的 OpenAI 兼容列表，DNS 所有答案均检查，连接固定到已检查地址，TLS 保持原主机校验，拒绝所有重定向，设置总时限及响应体限制。草稿发现不使用已存凭证，避免将其发送到草稿地址；用户可以明确输入测试密钥。常规模型推理仍由现有适配器实现，本次发现请求的网络策略不是整个进程的出站隔离。

## Alternatives considered

- 开放通用 settings/credentials：越过模型配置范围，拒绝。
- 用代理头伪造 loopback 或停用认证：削弱既有边界，拒绝。
- 为模型另建存储：产生重复状态所有者，拒绝。
- 直接调用普通 fetch 进行远程发现：缺少连接地址验证并允许重定向，拒绝。

## Acceptance criteria

参见根目录设计计划与本次聚焦拒绝测试、HTTPS 代理浏览器验收。未登录、CSRF、Host、代理、配置越权、凭证泄露、DNS 与重定向边界必须有独立证据。真实添加、密钥保存、模型列表与重启持久化均通过后才能报告功能验收；合并、发布和 Done 仍需对应证据及授权。

## Risks

当前范围只开放公网 HTTPS 发现；内网端点兼容问题已询问用户，尚无答复。既有推理适配器的全进程出站隔离不是本修复的实现范围，不能根据发现接口测试声称其已受保护。通用 GUI/主题门禁若有基线失败，必须单独报告。此变更尚未提交、上线或完成验收。
