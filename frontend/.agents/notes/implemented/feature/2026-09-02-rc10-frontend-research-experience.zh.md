# Agent Note: rc.10 能力导向的投研体验

Status: implemented

[English](2026-09-02-rc10-frontend-research-experience.md) | 中文

## Problem

多个投研页面在产品具备持久任务历史约定前就暴露了面向实现的控件。“智能分析”把能力发现和直接任务表单混在一起，“策略研究”首屏被生命周期教育与全局回测窗口占据，“实时盯盘”的悬浮助理会遮盖资讯栏，却没有协调布局或焦点。研究上下文还重复提供策略选择，而助理实际只需要分析能力和可选标的。

前端需要落实 rc.10 的信息层级，同时不能虚构后端任务历史、分页、关系来源或其他尚不存在的事实。

## Decision

“智能分析”是由无视图依赖的 `ANALYSIS_MODULES` 目录驱动的能力概览。四张卡片只提供详情与助理交接，不展示直接任务表单、本地模拟进度或后端执行控件。同一目录驱动智能分析助理与“我的投研”输入区的提示词模板选择。模板只修改当前输入草稿，不写入 system prompt、不改变工具权限，也不调用业务后端；模板选择及上一次自动草稿按会话保存，并与其他页面沿用的研究专家状态分离。其他业务页面继续保留既有研究专家选择。模板与可选标的彼此独立，切换模板只替换空白草稿或仍等于自动模板的草稿，普通对话不注入隐藏模板。

“我的投研”继续以对话为主界面。“偏好复盘”归属“研究工作台”，并与工作台使用保持挂载的同级视图，返回时不会重新挂载工作台或重复初始数据读取。

“实时盯盘”在页面边界派生 `closed`、`docked`、`overlay` 助理布局，以及 `comfortable`、`compact` 密度。桌面停靠态缩小页面可用宽度，并让仍保持挂载的资讯栏退出交互。窄屏使用模态遮罩并将工作台设为 inert。关闭后焦点回到助理入口。紧凑密度隐藏次级行情字段，同时保留标识、价格和涨跌幅。

“策略研究”把生命周期教育放入支持键盘操作的帮助弹层，并移除页面级刷新与回测窗口控件。在后端任务历史交付前，现有运行操作继续使用既定的两年请求，不展示虚假的历史管理器。“自进化”看板分开展示参与状态、置信层级与变异来源；变异不是可计数的生命周期分组。

“产业链”区分选中与重新定中心。单击节点只改变焦点和实体详情；“设为中心”会重新加载该公司，加载期间保留当前图谱，并在成功后原子替换已累积的图谱状态；加载失败时保留原中心和原图谱。1、2、3 层控件使用对应请求深度重新加载当前中心。图例同时提供文字标签与“供应商 → 当前企业 → 客户”的方向说明，因此颜色不是唯一信息载体。

过渡使用短时长的透明度和位移变化；需要恢复状态的数据表面保持挂载；`prefers-reduced-motion: reduce` 下取消这些动态效果。

## Deferred backend contracts

本决策不新增回测或影子任务历史、人工任务进度、关系权重来源、事件分页、影响扩展、风险中心数据或演示夹具。这些界面在对应后端约定存在前继续暂停。

## Alternatives considered

**保留“智能分析”的直接任务表单。** 这会保留熟悉控件，但继续混淆能力发现与执行，并暗示 rc.10 已交由持久任务历史持有的任务状态。

**打开助理时卸载“实时盯盘”资讯栏。** 这样可以减少布局工作，但关闭助理时会重复请求资讯并丢失滚动状态。

**继续把变异当作生命周期分组。** 一个变异候选还可能处于正常、观察或淘汰状态，把变异当参与状态会重复计数，也会掩盖来源与当前状态的区别。

**将每次产业链重新定中心都累积进同一图谱。** 这样会保留探索历史，但重新加载后旧根仍留在视图中，可能被误认为当前中心。

**模拟缺失的后端历史与分页。** 占位记录会让界面看似完整，却违反投研事实必须来自真实约定的产品要求。

## Consequences

各投研页面首屏现在优先呈现用户需要做的判断，而不是后端机制。助理过渡能够保留上下文与可访问状态，响应式密度也成为明确、可测试的状态。移除全局回测控件后，旧直接运行操作暂时不再支持用户选择窗口；该能力随真实任务历史管理器恢复。产业链重新定中心成功后会有意替换旧累积图谱，确保可见根节点与请求对象不会分离。
