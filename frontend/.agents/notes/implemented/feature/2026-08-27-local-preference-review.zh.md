# Agent Note: 本地偏好复盘与学习事实

Status: implemented

[English](2026-08-27-local-preference-review.md) | 中文

## Problem

投研产品已经能够归因策略结果与内容效果，却没有一条受治理的本地事实流来记录用户自己的研究行为。用户无法检查自己反复打开、带入分析或明确标记为相关的内容，后续自进化也没有可引用、可复现的偏好快照。若复用自由格式的浏览器分析事件，搜索词、提示词、文章正文、组合金额或凭据可能被持久化；若把这些事实发送到外部交易 endpoint，又会违背产品的本地边界。

历史行为画像还曾把兴趣证据与 `aggression_delta` 混合，风险预警也曾允许负向内容反馈影响严重度。这些路径可能把好奇或厌烦转化为风险承受能力变化，不符合适当性决策要求。

## Decision

界面为每次挂载的投研产品创建一个有界、仅驻内存的埋点记录器。它只记录枚举化的页面访问、有效曝光、打开、带入分析和关注变化。有效曝光要求至少 50% 可见并持续一秒，且每个界面会话内去重；React effect 的短时重放使用 750 毫秒窗口吸收。每条事件只包含不透明事件 id、不透明会话 id、结构化目标 id 和固定上下文投影，绝不包含客户端时间、搜索文本、提示词、内容标题与正文、组合数量与成本、URL、路径或凭据。记录失败在附属能力边界被吞掉，绝不阻塞产品动作。

Host 提供个性化反馈，以及事件写入、状态、设置、定向清空和确定性复盘五个固定本地学习 operation。输入会在获取后端租约前验证。这些 operation 只允许通过 `owned` 或 `attached` trading-core 租约执行；`external` 租约会在任何网络请求前被释放并拒绝。Python 适配器生成 UTC 时间，拒绝未知字段和自由文本标识，按事件 id 去重，并以原子方式在新事件、兼容交互和当前反馈之间共享 90 天与 2,000 条上限。同一对象的反馈以后写值为准。暂停只停止新增学习事实，不改变正常研究行为；二次确认清空只删除学习事实，保留持仓、显式风险数据、策略、验证结果和报告。

“我的投研”持有一个“偏好复盘”子页面，提供近 7 天与近 30 天视图、明确的小样本状态、证据数、活跃天数、置信度、曝光到打开再到分析与反馈的漏斗、近期结构化活动、安全聚合导出、暂停／恢复和确认清空。后端使用带版本的固定权重生成证券、行业和策略排行，并附带由内容计算的快照 id。非关键卡片排序可以使用这些兴趣证据和原因码；关键预警、显式风险承受能力、风险预算、策略生命周期和适当性保持独立。历史风险调整字段固定为零，有效激进度始终等于显式画像，预警严重度忽略反馈，策略 outcome 归因也只作为策略证据。

## Verification

后端测试覆盖 schema 投影、敏感字段与自由文本拒绝、权威时间、批次原子性、重试幂等、共享时间与数量保留、无需后续写入的到期清理、暂停、反馈纠正、定向清空、确定性快照、小样本和 API 路由。安全回归断言反复阅读利空、策略 outcome 为正，以及反复标记预警无用，都不能修改显式风险或预警严重度。

Host 测试覆盖所有固定路由与请求体、租约获取前的非法输入拒绝、严格上下文值，以及外部模式下六个本地 operation 均不执行 `fetch` 且仍释放租约。界面测试覆盖有界去重、记录失败隔离、有效曝光计时、安全反馈与纠正、偏好复盘进入与返回、时间窗口、证据、小样本、可重试失败、暂停／恢复、二次确认清空和安全导出。投研包还通过常规类型检查、构建、组件、覆盖率、GUI、Web 快照和运行时矩阵门禁。

## Alternatives considered

**使用通用分析 SDK 或远程事件服务。** 这会引入第二套身份与保留系统，并把外发变成默认行为。产品需要的是用户可复盘的本地事实源，而不是增长分析。

**先持久化任意事件名和元数据，再在复盘时脱敏。** 原始提示词、搜索文本、内容或组合金额一旦写入，后续投影无法恢复数据最小化。封闭协议会在获取租约与存储前拒绝这些数据。

**从点击、阅读时长或负向反馈推断风险承受能力。** 研究兴趣不等于风险承受能力。显式适当性输入仍是风险承受能力和预算的唯一来源，行为只能影响非关键内容排序。

**保存客户端时间并由浏览器负责保留窗口。** 客户端时钟可被修改，会使复盘窗口与删除不可复现。本地后端负责生成权威 UTC 时间。

**建立第二套偏好数据库。** 既有原子 JSON 存储已经持有本地投研状态和兼容行为。使用同一份受治理的行为文档，可以避免双写漂移并支持渐进迁移。

## Consequences

用户可以检查并控制个性化背后的本地证据，后续归因或自进化也能引用确定性、带版本的快照，而不是不透明分数。浏览器不持有长期分析数据库，远程交易服务不会通过该约定收到偏好事实，埋点故障也不会降低研究动作可用性。

首个版本采用单用户模式，只提供固定的 7／30／90 天复盘窗口，并且在至少三个有效信号跨越两天前刻意不输出结论。偏好导出是聚合摘要，不是原始数据。新增事件类型或上下文字段必须同时经过界面、Host 与后端的显式协议和隐私复核；任意元数据不是扩展点。
