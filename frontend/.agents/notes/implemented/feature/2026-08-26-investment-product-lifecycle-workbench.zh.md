# Agent Note: 投研产品生命周期工作台

Status: implemented

[English](2026-08-26-investment-product-lifecycle-workbench.md) | 中文

## Problem

投研 Profile 已能展示真实行情和持仓数据，但其余研究能力仍以互不关联的占位页呈现。异步分析产生的报告没有产品级统一入口，策略证据无法连续进入影子验证与自进化，浏览器若自行提供模型上下文就需要把业务 JSON 复制进会话输入框。工作区只决定本机存储范围，却占据主导航和空白对话的显著位置。

多个股票输入还共用一个路由值，一个页面的选择或编辑可能意外改变另一个页面。新建对话也可能与尚未完成的智能助手预填发生竞态，使旧草稿落入新会话。

## Decision

投研侧栏按生命周期依次呈现智能分析、实时盯盘、策略研究、影子验证、自进化、我的投研和产业链。既有路由 id 只作为内部呈现细节，选择状态则在相关流转中保留股票与策略标识。策略研究通过固定 Host operation 生成假设、运行回测并更新生命周期；影子验证读取纸面账户状态、持仓、净值与任务；自进化读取归因，并要求先展示只读预案，再由用户明确确认写入。

浏览器只持有视图状态、互相独立的模块草稿和选中的不透明标识。行情事实、策略生命周期判断、纸面账户记录、归因和报告都归后端持有。浏览器请求使用编译期 `InvestmentDataOperation` 清单；Host 在获取后端租约前拒绝未知键，并验证动态报告、策略和任务标识，再把它们编码进固定路由。

每个成功的 trading-core 异步任务都会投影为持久报告记录。全局“投研报告”入口列出稳定元数据，并按有序章节读取单份报告，使分析、回测和验证结果拥有同一个查看路径，同时不向浏览器暴露内部任务载荷。

量化任务会在正常结果中返回可审计的 Markdown 章节。报告存储根据策略名称、策略标识、验证范围和交易日生成可读标题；客户端把报告类型和时间本地化，并把标题、列表与表格渲染为真正的文档结构。策略回测只有在实际返回报告章节时才提示归档成功；影子验证若显式收到候选策略则按失败关闭处理，显示未执行原因，而不会暗示纸面交易已经运行。

AI 操作把有类型的界面意图转换为简短自然语言指令，绝不把业务数据序列化进输入框。模型通过 `investment_context` 的固定领域 `portfolio`、`strategy`、`shadow`、`evolution`、`reports` 或 `industry`，或者既有股票与盯盘工具读取当前后端状态。该工具不接收上下文 JSON、URL 或路径，结果沿用可持久重放的正式工具调用生命周期。

Profile 把工作区上下文标记为设置项。共享会话在该通用位置标记下保留智能体预设，只隐藏工作区 chip 与 picker；投研设置复用正式 Workspace 与 Session 服务切换本机存储位置。首次使用时即使尚未选择存储位置，也可通过隐式会话目标直接开始；被视觉覆盖的工作区表层也会同时退出键盘和无障碍导航。新建对话会取消尚未完成的预填所有权，并显式清空新会话草稿。全局证券搜索、智能分析股票输入、盯盘选择和产业筛选分别持有独立状态。

普通 Web 子进程不再提前加载可选的 PTY 原生模块。本地子进程适配器只在真正请求终端时导入 `node-pty`，使产品启动和浏览器回归不再依赖终端原生模块是否可用。

既有[投研数据渐进加载决策](2026-08-24-investment-data-progressive-loading.md)继续负责实时盯盘与我的投研的资源独立结算和旧响应保护。本记录不取代工作区产品流程，只改变该 Profile 展示工作区选择的位置。

## Verification

组件契约覆盖七个导航入口、报告读取与 Markdown 渲染、有类型且不注入 JSON 的助手意图、独立草稿、新会话草稿清空、仅设置页切换工作区、对话框与抽屉焦点所有权，以及仅由显式交接保留策略选择。Host 与工具测试覆盖 operation 白名单、获取租约前拒绝非法输入、上下文领域路由、报告投影、任务标识验证、只允许生效策略进入影子验证和真实 Loader 组合。无密钥投研 headless 场景组装生产工具集合，并通过持久会话事件重放 `investment_context`、股票分析和盯盘调用。

同时还使用构建后的投研 Profile 完成了真实浏览器产品验收：覆盖全部七个模块、真实策略回测与持久报告往返、直达影子验证时不携带旧候选策略、未配置工作区的首次会话、全局搜索/智能分析/会话输入的独立状态、新建对话空白行为、仅设置页展示存储位置、深色模式，以及从桌面到 390 像素宽度的响应式布局。最终页面会话没有产生浏览器错误。

## Alternatives considered

**在形成独立产品前继续保留四个占位导航。** 后端已经持有策略、影子、自进化和影响数据。保留不可用页面只会隐藏已有能力并延续断裂的研究交接，不能降低产品风险。

**把页面完整 JSON 状态复制进预填提示词。** 这会在浏览器复制后端事实，使输入框难以阅读，在模型判断所需事实前就消耗 token，并绕开可持久追溯的工具调用记录。

**只在发起任务的页面或对话保存报告。** 用户必须记住每个任务来自哪个模块和会话，导航后也难以发现后台完成的结果。后端报告索引为全部产品表层提供同一份持久事实。

**计算后立即应用自进化动作。** 归因可能尚不完整，而自进化会改变策略生命周期。先预览再确认可以保留操作者权限，并把模型解释与真实写入分开。

**使用投研 Profile 专属选择器隐藏工作区控件。** 让共享会话包认识某个 Profile 名称，会把存储位置变成主题例外。通用位置标记能够表达产品选择，同时让其他 Profile 保持正常工作区表层。

## Consequences

该 Profile 形成从发现到组合动作的连续证据路径，模型上下文保持精简且可重建，生成报告也有稳定归宿。用户在策略研究、纸面验证与自进化之间流转时无需重复选择策略，互相独立的输入也不会彼此覆盖。

所有业务页都依赖 Host operation 清单和后端响应字段；服务不支持或不健康时，界面显示可重试的空状态或错误状态，不使用模拟内容。任务轮询无法取消后端工作，并且前台等待有明确上限，但持久报告中心会保留稍后完成的结果。工作区创建与高级管理仍归既有工作区产品所有，该 Profile 只在设置中提供存储位置选择。
