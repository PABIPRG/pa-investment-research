# Agent Note: 候选假设预览展示证券名称

Status: implemented

[English](2026-09-23-hypothesis-preview-security-names.md) | 中文

## Problem

策略候选假设预览只显示六位证券代码。用户在决定是否加入候选池前难以辨认关联标的。

## Decision

预览复用现有的证券名称解析器和策略标的解析逻辑，在代码前显示查到的名称。证券目录暂时没有返回名称时，明确显示“名称待补充”及代码，不虚构名称。

## Alternatives considered

**仅保留代码并增加查询链接。** 用户仍需离开确认内容执行额外操作才能认出标的。

**把当前看到的代码和名称写死。** 这种映射会过时，也绕开共享证券目录。

## Consequences

目录返回名称后，预览以名称加代码展示标的。查询失败或尚未完成时，代码仍可见，并有明确的名称缺失提示。假设未携带有效名称时，预览会查询对应代码。
