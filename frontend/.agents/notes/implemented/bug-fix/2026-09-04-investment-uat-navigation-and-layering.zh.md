# Agent Note: 投研 UAT 导航与层级修复

Status: implemented

[English](2026-09-04-investment-uat-navigation-and-layering.md)

## Problem

真人产品验收暴露出投研工作区中数个相互关联的体验缺口：进入单策略影子验证后没有返回全部策略的路径；已有策略详情弹框时打开报告，报告会落在后层；相邻的提示词模板与标的选择器可以同时展开，视觉也不一致；进化与回测证据仍显示机器化标题或使用过密的卡片样式。产业链图谱还把未关联证券代码的实体描述成已有证券档案，演示脚本则把同一发布流程拆成了重复的顶层入口。

## Decision

影子范围栏提供明确的“查看全部策略”返回入口。报告与详情遮罩使用相同层级，由既有 UI 状态与 portal 渲染顺序让后打开的报告自然位于上层，同时保留详情状态。提示词模板与标的选择器由父级统一控制当前展开面板，并使用一致的菜单容器视觉。

回测历史采用响应式任务卡片。策略分类总数在首次加载期间保持未知，不显示虚假的零值；候选创建按完整可执行策略语义原子去重，同时保留行为参数不同的策略。自进化看板从真实生命周期分组中的 `source` 与 `mutated_from` 字段派生变体，不要求独立的 mutated 分组；数据就绪状态按已观察日数与最低门槛展示，不使用超过门槛的分数形式。生命周期明细仍可从状态计数进入，但限制显示高度，避免大量候选策略占满首屏。进化页面使用中性色表面、清晰间距，并用 `证券名称(代码) · 中文策略类型` 作为面向人的策略标题；原始策略类型和内部策略标识仍保留在数据层，但不再作为标题。

产业链接口若以 `503` 明确表示种子数据未就绪，将进入独立的重试退避，不触发“服务不可达”熔断。这既保持请求路径响应快速，也能区分“服务可用但等待数据”与“服务不可用”。

报告刷新操作复用既有主按钮契约，并放大为通栏点击区。智能分析与“我的投研”都以同一种上下文外观渲染既有 `InvestmentPromptTemplateSelect`，复用共享菜单基础组件，不新建平行选择器。没有证券代码的产业实体显示“未关联 A 股代码”。发布演示脚本只暴露一个顶层入口，再通过子菜单承载数据准备、演示前检查、全链路彩排、验证与清理，同时保留隐藏命令别名以兼容原有用法。

## Alternatives considered

**打开报告前关闭策略详情。** 未采用，因为这会丢失有用上下文，而且没有必要；产品已经能同时表达两层弹框，相同层级下后渲染的 portal 即可成为前景。

**让每个选择器独立维护展开状态和样式。** 未采用，因为相邻选择器会发生重叠并持续产生视觉漂移。统一的受控面板契约明确保证互斥，同时保留既有菜单基础组件的 Escape、外部点击和焦点行为。

**直接展示后端策略名称。** 未采用，因为 `rsi_reversal` 与不透明内部标识属于实现词汇，不适合作为投研标题。

## Consequences

用户可以从局部范围返回、在阅读报告时保留详情上下文、更快扫描证据，并看到真实且可理解的领域语言。自进化页先说明是否真正发生进化，再展开运行明细；同时保留空数据、未启用、部分数据可用和历史状态，不虚构进化活动。重复来源事件不会继续向策略池增加可执行语义完全相同的候选，已有历史记录保持不变。产业种子数据未就绪时，扩展逻辑现在仅在一个退避周期内降级，不会误报服务故障。前端集中映射后端策略类型和证券代码，未知类型会回退到通用描述，而不是泄漏机器文本。弹框前后关系依赖相同层级下后打开 portal 的文档顺序，并由定向交互测试与样式测试覆盖。
