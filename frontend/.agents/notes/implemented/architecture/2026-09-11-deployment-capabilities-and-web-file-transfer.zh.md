# Agent Note：部署能力显式化，浏览器备份传输有明确边界

状态：已实现

[English](2026-09-11-deployment-capabilities-and-web-file-transfer.md) | 中文

## 问题

本机 Web、Electron、CLI 与云端 Web 共用 UI 和 Host 方法，却缺少权威的部署形态声明。浏览器平台推断可能选中本地券商适配器；经过认证的云端客户端仍可能发现或提交服务端路径。投研备份只支持 Host 本地文件，因此云端浏览器既不能导入用户选择的文件，也不能下载已有归档。

## 决策

`@deepseek-ai/dsh-host-deployment-capabilities` 为整个进程提供一份不可变快照。基础组合声明 CLI；Web 启动通过 `DSH_DEPLOYMENT_SURFACE` 显式声明 `local-web` 或 `cloud-web`；Electron 将其覆盖为 `electron`。`host.describe` 把该快照交给 Client。

消费方依据快照采用 fail-closed（失败时关闭能力）策略。云端 Web 不挂载目录选择器；Host、Session、Workspace 与投研 Runtime readiness 投影不包含 Host 路径；带路径的创建方法与原生打开方法会被拒绝；持仓只允许手工录入或批量导入。本地形态保留既有的平台数据源名单和就绪诊断。

投研备份传输继续使用既有的分块 Remote 流程和导入预览。已存备份下载使用独立、有界的 Remote 会话，因此每个分块都受认证传输保护，同时避免无上限请求体。Host 会在文件 I/O 或归档解压开始前原子预留容量：两个下载会话、两个预览会话及 128 MiB 压缩字节预览总上限、四个上传会话及 128 MiB 上传预留总上限。它会复查已打开文件的大小，以固定长度读取，验证直接 `.pabackup` 归档，并要求精确 offset。所有创建传输资源的入口共用同一生命周期门禁：Runtime 释放会先关闭门禁，中止并等待进行中的创建，再清理会话、预留和临时文件。释放后的新建请求会 fail-closed。备份列表的文件错误使用稳定、不含路径的说明，不暴露 Node 原始错误。

浏览器把取消信号传入每个 Remote，检查声明区间、组装 Blob、触发下载并撤销对象 URL。用户确认导入时，预览所有权转交给 Host：导入成功后由 Host 消费，预览过期时关闭对话框，可恢复错误在页面挂载时保留预览以便重试，卸载后才失败则释放预览。存储位置操作在能力未知或读取失败时保持隐藏，只在 Host 明确返回本地存储后显示。

云端托管存储始终解析到实例拥有的默认目录。更早本机部署保存的自定义目录在云端 Web 中会被忽略，但仍会保留供之后的本机部署使用。预期内的备份失败通过明确可信、可安全展示给调用方的载荷跨越 Remote 边界；意外异常会转为稳定的通用拒绝，原始原因只保留在 Host 侧。

## 考虑过的其他方案

- 不采用从浏览器 API、URL 或监听地址推断部署形态，因为它们只是展示或拓扑细节，不是部署权限来源。
- 不依赖浏览器取消、后续请求或 24 小时惰性过期，因为放弃的会话可能长时间占用内存和临时文件。全局预留与活动的十五分钟计时器无需后续请求即可限制剩余存活时间。
- 不为传输附加猜测出的 owner，因为 Runtime 尚未收到可信的认证主体。只有把 owner 加入 Connection／Gateway 请求 Context，注销时才能同步且仅回收该主体的资源。

## 结果

- UI 可见性只是易用性处理；即使请求经过伪造，Host 检查仍执行同一套云端限制。
- 云端用户看到托管备份存储，可以下载、上传、预览、取消、重试、导入或清空，而不会获知服务端目录。
- 云端 Web 绝不执行券商发现或同步；UI 引导用户采用手工录入或批量导入。
- 部署矩阵记录在 [`docs/deployment-capabilities.md`](../../../../docs/deployment-capabilities.md)。
- Web 认证保持不变。传输尚未关联认证 owner，因此注销后资源可能继续存在，直至全局配额或活动的十五分钟计时器回收。关闭该限制需要通过 Connection／Gateway 请求 Context 传递认证 owner。容器隔离与健康／就绪仍是独立部署事项。

## 验证

包级测试覆盖四种能力快照、直接与 Loader 组合、显式启动解析、云端不挂载目录选择器、包括投研 readiness 在内的 Host 路径拒绝与脱敏、云端持仓拒绝、可信与通用 Remote 错误映射、原子传输预留、阻塞创建与释放的线性化、稳定且不含路径的列表诊断、活动过期清理、重试和卸载过程中的导入预览所有权、客户端分块检查／取消、fail-closed 存储加载、托管存储隔离、焦点恢复和无障碍进度。Web bundle 构建是独立交付门禁；完整的云端 Web 真实产品验收由 PAB-21 跟踪。
