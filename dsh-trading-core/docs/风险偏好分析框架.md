# 风险偏好分析框架（risk_profile）

> 不同风险偏好的用户适用不同的投资分析框架。风险偏好贯穿 个股分析 / 持仓分析 / 市场简报 三套框架，全局持久化 + 每次调用可覆盖，dsh 对话内可设置。

## 三档画像（单一事实源：`adapter/risk_profiles.py`）

| 画像 | key | 定位 | 组合波动率上限 | HHI 上限 | 单股权重上限 | β 上限 | 逐股风险分档 | 个股决策护栏 | 简报机会点 |
|---|---|---|---|---|---|---|---|---|---|
| 保守型 | `conservative` | 保本为先，严控回撤 | 12% | 0.20 | 15% | 0.80 | 高≥0.35 / 中≥0.20 | 买入但风险分>0.50 → 降级持有 | 只展示 ≤中 风险机会 |
| 稳健型 | `balanced` | 价值与成长均衡（默认） | 18% | 0.30 | 25% | 1.00 | 高≥0.50 / 中≥0.30 | 买入但风险分>0.65 → 降级持有 | 展示全部 |
| 进取型 | `aggressive` | 追求高收益，容忍波动 | 30% | 0.50 | 40% | 1.50 | 高≥0.70 / 中≥0.45 | 弱卖出信号(风险分<0.30) → 降级持有 | 展示全部，高风险置顶 |

- `risk_score` 是引擎风险经理从自由文本里抽取的 0~1 风险分（0 低 ~ 1 高）。
- 逐股风险等级（低/中/高）按画像 bands 计算：`risk_level_for(risk_score, profile)`。
- 预算对照在持仓分析里逐项检查，超限出「调仓建议」。

## 框架差异怎么生效（三套）

### 1. 个股分析（analyze_stock）
- **引擎注入**：`risk_profile` → `TradingAgentsGraph.config` → `GraphSetup` → `create_risk_manager(llm, memory, risk_preference)`，在风险经理提示词里插入对应偏好约束块（保守：宁错过不套牢、弱信号不追高；进取：可把握题材、须给止损位）。**balanced 为空串，提示词与引擎现状完全等价（零回归）。**
- **适配器护栏**：`calibrate_stock_decision(signal, profile)` 做确定性修正 —— 保守档买入但风险分超限 → 降级「持有」；进取档弱卖出信号 → 降级「持有」。`signal` 带 `risk_profile` / `calibration` / `calibration_note`。

### 2. 持仓分析（analyze_holdings）
- 组合指标（波动率 / HHI / 单股最大权重 / β）对照风险预算 → `risk_breaches` + `rebalance_suggestions`。
- 逐股打风险等级（低/中/高）。
- `_l2_deep` 给逐股引擎透传同一 `risk_profile`，逐股决策用同一偏好。
- 报告含「🎯 风险画像与预算对照」章节。

### 3. 市场简报（market_brief）
- 机会点按 kind 打风险等级：北向→低；板块/资讯/自选股异动→中；龙虎榜/市场过热/风险释放→高。
- 保守档过滤掉高风险机会点；进取档把高风险机会置顶。
- LLM system prompt 注入「面向{档}投资者」约束，要求每条机会点给出相称的风险提示。

## 如何设置

| 方式 | 说明 |
|---|---|
| dsh 工具 `set_risk_profile` | 保存到 store（`data/adapter/preferences.json`），全局持久化 |
| dsh 工具 `get_risk_profile` | 读取当前画像 |
| 单次调用 `risk_profile` 参数 | analyze_stock / analyze_holdings / market_brief 均接受，覆盖全局偏好 |
| `.env` `RISK_PROFILE=` | 仅作 store 为空时的缺省兜底 |

优先级：**调用参数 > store 持久化 > .env > balanced（默认）**
