## 设计与串行集成

顺序：提取 PAB-32 → 提取 PAB-33 → 同步版本及通用文档 → 聚焦测试与构建 → 本地真实验收 → 范围审查 → 提交及跨仓 PR。每步以来源基准一致、无未知改动、不引入专属运维信息为继续条件。验证失败区分本次回归、既有失败和环境限制；不能把旧主线 CI 当作本次证据。

密码由 web-auth 独占，设置插件只贡献表单；成功提交密码文件后才更新内存并撤销会话。失败保持旧密码，网络中断明确提示结果未知。部署 secret 仅首次初始化；离线恢复复用实例锁。替代方案“每次启动覆盖 secret”会丢失用户修改，故不采用。旧版回滚可能恢复初始 secret 密码，详见[实例密码管理](../maintainers/实例密码管理.md)。

产业链保持现有固定文件列表、流式硬上限与原子替换，仅调整单文件至 128 MiB、总量至 256 MiB。界面根据已知错误提供超限、校验、网络及通用提示，不展示原始异常；不改变查询与下载状态所有权。

| 用户动作 | 入口与所有者 | 复用判断 | 成功结果 |
|---|---|---|---|
| 修改密码 | 设置 → 账号安全；web-auth | 组合 settings.section、Input、Button；不新增设置文档字段 | 全部旧登录失效，新密码重新登录，研究数据保持 |
| 下载 / 重试 | 产业链既有缺数据页；SeedDataManager | 扩展既有状态与提示 | 五文件完整校验后发布；失败保留既有数据 |

| 状态 | 改密 | 产业链 |
|---|---|---|
| 加载 / 刷新 | 提交禁用、防重复；会话检查与改密协调 | 沿用下载进度及状态轮询 |
| 空数据 / 无筛选结果 | 空字段禁用；筛选不适用 | 缺数据引导下载；查询筛选行为未改变 |
| 部分成功 / 过期 | 不允许部分密码提交；过期要求登录 | 不发布半套文件；原数据保留 |
| 错误 / 无权限 | 字段错误、保存失败、结果未知、401/CSRF | 已知错误分类；未知异常隐藏 |
| 成功 / 确认 / 撤销 | 提交前说明全设备注销；清空不发送；成功不能撤销 | 显式下载，失败可重试 |
| 响应式与主题 | 复用主题 token、表单换行与设置滚动容器 | 保留现有布局；检查长错误文案 |
