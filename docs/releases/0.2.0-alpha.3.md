# 投研智能体 0.2.0-alpha.3 候选发布说明

本文件为候选说明，尚未发布，也不表示全部发布门禁通过。比较起点为 [investment-v0.2.0-alpha.2](https://github.com/PABIPRG/pa-investment-research/releases/tag/investment-v0.2.0-alpha.2)（2026-09-16，`2962414b`）；候选包含其后主线 `8f10ff29` 及本次收口代码。主线区间有 46 个合并 PR；最终 tag、附件和校验值须由另行授权的发布流程产生。

## 主要变化

- **账号安全与产业链下载：** 登录后可在“设置 → 账号安全”修改当前实例密码，成功后所有旧设备重新登录，重启保留新密码。管理员有停服恢复工具。产业链单文件上限提高至 128 MiB、总量 256 MiB，超限、校验和网络失败显示不同提示，失败保持旧数据。
- **研究和资产操作：** 主线加入通知中心与通知配置、成交导入和持仓计划，完善原生持仓读取与 OCR 前置检查、手工成交时间记录、自选及策略提示。这些能力的目标平台验收仍以对应工作项为准。
- **公开观察室：** 主线提供独立只读观察室，基于真实持仓与行情，支持 T+1 批量浏览、历史播放和日历状态，区分休市、无记录、缺估值与待更新；不把持仓金额冒充完整账户权益。
- **启动与交付：** 主线改进启动恢复、侧车下载重试与缓存、镜像拉取诊断及依赖安全；桌面、Web 应用身份和控件样式保持一致。已有部署工具不代表本次执行了部署。

## 升级与回滚

升级前备份完整应用数据卷。容器首次运行本版会把初始 secret 转为实例内持久化密码记录；后续重启不会覆盖用户密码。旧版本回滚可能重新采用旧 secret 密码，不能只切换镜像后假定新密码仍有效。管理员恢复须停服且持有相同实例锁；详见[实例密码管理](../maintainers/实例密码管理.md)与[容器部署与回滚](../maintainers/容器部署与回滚.md)。

下载体积上限不是内存配额；大 JSON 解析与查询缓存仍需在目标环境验证。单密码文件只支持单服务进程。本版没有多用户账号库或多副本会话共享。

## 验证与已知限制

本次组合验证和证据见[收口记录](0.2.0-alpha.3-收口记录.md)。旧主线镜像检查、旧 PR 打包和来源工作区的测试均不替代候选验证。来源已有全量 GUI/Web 失败记录，不宣称全门禁通过。
