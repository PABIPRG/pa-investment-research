# 工作区弱感知与设置

> 需求前缀：`WORKSPACE`

## 1. 产品结论

工作区是正式会话与本机数据的存储组织方式，不是用户完成投研任务必须理解的业务概念。1.0 将它收纳到设置，不在主导航、产品标识或空白新会话中突出展示。

## 2. 主流程要求

| ID | 要求 | 级别 |
|---|---|---|
| WORKSPACE-001 | 左上产品区不显示当前工作区选择器 | P0 |
| WORKSPACE-002 | 新建对话与输入框不显示工作区 Chip、Picker 或占位文案 | P0 |
| WORKSPACE-003 | 未手动选择工作区时，系统自动使用默认或上次存储位置 | P0 |
| WORKSPACE-004 | 未选择工作区不得阻断 1+7 页面和空白会话输入 | P0 |
| WORKSPACE-005 | 设置中以“数据与存储”为用户可理解入口 | P0 |
| WORKSPACE-006 | 高级说明可提及工作区，但需解释其只影响会话/本机存储 | P1 |
| WORKSPACE-007 | 切换前说明对未发送草稿和当前会话的影响 | P0 |
| WORKSPACE-008 | 切换存储位置不静默迁移、删除或重归属业务报告和持仓 | P0 |

## 3. 首次使用

- 系统自动准备默认本机存储位置。
- 用户可以先浏览直接数据页，再决定是否配置模型。
- 初次声明或模型配置提示可跳过，不得要求用户先创建或选择工作区。
- 默认位置准备失败时，用“本机数据位置不可用”描述问题，并提供设置入口；不抛出内部 ID。

## 4. 设置页内容

“数据与存储”至少说明：

- 当前会话历史保存位置。
- 切换后从哪个新会话开始生效。
- 哪些业务事实不受影响，例如后端持仓、策略和报告。
- 是否存在未发送草稿或运行中的会话。

通用工作区创建、删除、共享与权限管理不在投研 1.0 主流程范围内。

## 5. 切换规则

- 用户明确确认后才切换。
- 未发送草稿默认保留在原会话，不自动复制到新位置。
- 切换后创建新会话；当前业务路由与只读页面状态可保留。
- 切换失败保持原位置有效，并提供可重试信息。

## 6. 验收

- 首次启动不选择工作区也能进入 1+7 页面并在空白会话输入。
- 左上、侧栏主导航和新建对话均搜索不到面向用户的工作区选择器。
- 设置中能查看和切换存储位置，取消与失败均不丢草稿。
- 切换后持仓、策略和投研报告不因会话存储变化而消失。
