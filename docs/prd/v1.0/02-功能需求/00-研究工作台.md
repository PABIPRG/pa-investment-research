# 研究工作台

> 需求前缀：`DASH`

## 1. 产品目标

让用户进入产品后先看到“今天最值得关注什么、组合有什么风险、下一步做什么”，而不是另一份聊天记录或空白数据大屏。

## 2. 页面范围

- 组合资产与持仓数量摘要。
- 高优先级风险预警。
- 当前风险画像与预算提示。
- 与持仓、自选和策略相关的市场事件。
- 按画像与分散化要求排序的策略匹配。
- 生成盘前简报，并进入统一报告中心。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| DASH-001 | 默认进入研究工作台，一级导航正确选中 | P0 |
| DASH-002 | 各摘要区独立加载；一个区域失败不清空其他区域 | P0 |
| DASH-003 | 事件支持全部、持仓、自选、策略四类范围筛选 | P0 |
| DASH-004 | 每条事件显示相关原因、数据时间和可执行下一步 | P0 |
| DASH-005 | 风险预警按严重度排序，并能进入我的投研或相关对象 | P0 |
| DASH-006 | 策略匹配说明匹配依据，不只显示分数 | P1 |
| DASH-007 | 生成盘前简报后立即显示任务状态，完成后可打开报告 | P0 |
| DASH-008 | 刷新期间保留上次成功值和时间，不闪回全空状态 | P0 |

## 4. 核心流程

1. 页面并行读取持仓、自选、画像、预警、事件和策略匹配。
2. 先完成的区域先展示，数据不足的区域给出明确空状态。
3. 用户从事件或预警进入目标业务域，系统携带最小对象标识。
4. 用户生成简报后可离开页面；任务继续运行，结果进入投研报告。

## 5. 空状态与失败

- 无持仓：引导前往我的投研，不伪造资产金额。
- 无相关事件：说明当前筛选无结果，可切换范围或刷新。
- 无策略：说明需先在策略研究创建候选。
- 后端失败：区域内显示失败和重试，不使用全屏错误替代工作台。
- 数据过期：显示“上次更新于”，不得仅显示看似实时的旧值。

## 6. 验收

- 冷启动、部分失败、全空、有完整数据四种场景均可理解。
- 点击事件、风险和策略入口后，目标页对象正确且返回状态保留。
- 盘前简报成功、失败、前台超时都能在报告中心找到对应记录。
- 无模型密钥时工作台可浏览；只有简报或助理解读能力提示配置。

## 7. 范围外

- 工作台内直接编辑全部持仓或策略。
- 自动执行任何风险处置或策略变更。
