# 投研助理

> 需求前缀：`AI`

## 1. 产品目标

在不离开当前业务页的情况下，用自然语言解释真实投研事实、比较方案并延伸研究。助理复用正式会话、模型、附件、审批和历史能力。

## 2. 入口

- 常驻“打开投研助理”入口。
- 业务页中的“解读、继续研究、在助理中分析”等显式动作。
- 报告详情中的“继续研究”。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| AI-001 | 打开助理不改变业务路由或丢失页面状态 | P0 |
| AI-002 | 右侧停靠助理在常用桌面宽度不遮挡关键确认动作，近全屏态提供明确收起与关闭 | P0 |
| AI-003 | 页面动作创建独立会话，并只预填可读自然语言意图 | P0 |
| AI-004 | 输入框不得出现系统生成的业务 JSON、URL 或内部路径 | P0 |
| AI-005 | 模型按需调用统一上下文和领域工具读取事实 | P0 |
| AI-006 | 工具调用及数据不可用状态对用户可追溯 | P0 |
| AI-007 | 用户点击“新建对话”后看到完全空白的新会话 | P0 |
| AI-008 | 历史会话支持搜索、打开、重命名和归档 | P1 |
| AI-009 | 模型未配置时提供局部配置提示，不阻断直接数据页 | P0 |
| AI-010 | 助理不能静默执行策略迁移、自进化或其他高影响写入 | P0 |
| AI-011 | 助理具有 `closed / docked / expanded` 三态，并与业务路由、业务草稿和任务状态相互独立 | P0 |
| AI-012 | 助理不得占用“智能分析”一级导航；智能分析始终是结构化任务工作台 | P0 |

| AI-014 | `Escape` 执行 `expanded → docked → closed`，关闭后焦点返回原打开入口 | P0 |
| AI-015 | 展开、收起和关闭复用同一正式会话，不中断流式输出或后台业务任务 | P0 |

## 4. 会话行为

- 常驻入口打开当前有效助理会话；没有会话时创建空白会话。
- 业务页显式研究动作创建新会话，预填例如“分析 600519 的当前风险”，上下文由工具读取。
- 新建对话原子清空文本、附件、命令状态和任何待完成预填。
- 关闭再打开助理可恢复会话，但不得修改业务页当前选择。
- 右侧停靠态建议桌面宽度为 380～420px；窄屏转为保留安全边距的覆盖式面板。
- 近全屏态使用具名模态语义、焦点约束和柔和遮罩，背景业务页保持挂载。
- 新建对话只重置会话内容和会话模块选择，不清空业务页表单、筛选、任务和报告。

## 5. 回答规范

- 区分后端事实、模型推断和未知信息。
- 关键结论引用证券、报告、策略或关系对象，并说明数据时间。
- 数据不可用时明确说明，不用常识补成当前事实。
- 不给出收益保证，不把影子结果描述成真实账户业绩。

## 6. 验收

- 逐一从 6 个一级业务入口及影子验证视图打开助理，页面状态不丢失，意图正确。
- 任一系统生成预填均不包含序列化 JSON。
- 新建对话与异步预填竞态回归 100 次无旧草稿串入。
- 模型工具读取失败时，回答与页面都保持可理解和可重试。
- 助理可完整执行关闭、停靠、展开、停靠、关闭状态链，期间业务路由和表单值保持。
- 智能分析业务页在助理三态中始终保持挂载，任务卡和进度不变。

## 7. 范围外

- 为投研 Profile 另造一套消息、附件或审批系统。
- 允许模型调用任意后端地址或路径。
