# 影子验证

> 需求前缀：`SHADOW`

## 1. 产品目标

用可追溯的纸面账户持续观察活跃策略，记录模拟持仓与净值，为复盘和自进化提供事实，而不触发真实交易。

## 2. 页面范围

- 当前策略与运行状态。
- 当日影子运行。
- 模拟持仓、整体或策略净值、最近运行记录。
- 运行错误、数据准备情况与自进化就绪提示。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| SHADOW-001 | 只允许对有效活跃策略运行影子验证 | P0 |
| SHADOW-002 | 从策略研究进入时默认保持同一策略 | P0 |
| SHADOW-003 | 同一策略同一交易日重复触发必须幂等 | P0 |
| SHADOW-004 | 运行中显示任务状态，完成后刷新状态、持仓和净值 | P0 |
| SHADOW-005 | 持仓显示证券、方向或数量、成本、当前值和更新时间 | P1 |
| SHADOW-006 | 净值曲线不足两个有效点时明确说明，不画误导曲线 | P0 |
| SHADOW-007 | 所有数值明确标注“模拟/影子”，不得与真实账户混淆 | P0 |
| SHADOW-008 | 失败运行保留日期、策略和原因，并允许安全重试 | P0 |
| SHADOW-009 | 达到进化门槛时可进入自进化并携带策略标识 | P0 |
| SHADOW-010 | 每次运行形成可追溯记录；重要结果可形成报告 | P1 |

## 4. 运行规则

- 页面按钮触发固定业务动作，不允许传入任意日期路径或执行脚本。
- 运行前展示策略、交易日和模拟性质。
- 后端决定交易日有效性、记账规则和幂等；前端不自行计算最终账本。
- 前台超时后可离开页面，报告中心或返回页面能恢复状态。

## 5. 空状态

- 无活跃策略：引导前往策略研究。
- 尚未运行：解释第一步和模拟性质。
- 无持仓：区分“策略当前空仓”与“尚无运行数据”。
- 净值不足：展示已有点数与自进化所需门槛。

## 6. 验收

- 重复点击或刷新不会产生重复账本。
- 策略切换时晚到响应不覆盖当前策略。
- 关闭页面再返回能读取最终运行结果。
- 全页面不存在券商委托、资金划转或真实下单暗示。
