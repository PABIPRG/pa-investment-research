# 投研报告

> 需求前缀：`REPORT`

## 1. 产品目标

为全部异步研究成果提供一个统一、持久、可再次打开的查看入口，消除“任务在哪个页面或会话发起，就只能回哪里找”的问题。

## 2. 全局入口

“投研报告”作为全局成果入口，和生命周期导航视觉分区，不计入 7 个业务域。以下位置必须可进入：

- 产品全局导航或固定工具区。
- 任一任务运行状态与完成提示。
- 报告生成后的成功通知。

## 3. 报告来源

- 个股分析、持仓分析、市场简报和历史回测。
- 策略假设、策略回测和重要状态变化。
- 影子验证阶段性结果。
- 自进化归因、预案和应用结果。
- 后续经 PRD 批准的其他投研任务。

## 4. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| REPORT-001 | 所有成功异步任务自动投影为持久报告记录 | P0 |
| REPORT-002 | 任务创建后即可看到 `processing` 报告占位 | P0 |
| REPORT-003 | 列表展示标题、类型、来源、状态、对象、创建和更新时间 | P0 |
| REPORT-004 | 支持按状态、来源模块、报告类型和时间筛选 | P1 |
| REPORT-005 | 报告详情按稳定顺序展示摘要、结论、证据、风险和附录 | P0 |
| REPORT-006 | 详情不暴露内部任务载荷、任意路径或敏感配置 | P0 |
| REPORT-007 | 报告可返回来源页面，并可继续研究或形成策略 | P0 |
| REPORT-008 | 前台超时后，后台完成结果自动更新同一报告记录 | P0 |
| REPORT-009 | 失败报告保留可理解原因和安全重试入口 | P0 |
| REPORT-010 | 同一任务只有一个报告身份；重新运行生成新版本记录 | P0 |
| REPORT-011 | 报告显示数据截止时间、生成时间和模拟性质 | P0 |
| REPORT-012 | 列表空态说明哪些动作会生成报告 | P0 |

## 5. 报告最小元数据

- 报告标识、标题、类型和状态。
- 来源模块、来源任务、来源业务对象。
- 创建时间、更新时间、数据截止时间。
- 有序章节、摘要、错误或不可用说明。
- 模拟/真实数据标记和风险提示。

具体字段和接口进入设计文档。

## 6. 一致性规则

- 报告完成态是不可变快照；新结果不静默覆盖旧报告。
- 源任务、源页面和报告中心对同一任务显示一致状态。
- 报告删除、公开分享和协同编辑不进入 1.0，避免提前引入复杂权限语义。
- 会话归档不删除报告；工作区切换不应让业务报告无故消失。

## 7. 验收

- 从四类智能分析任务、策略回测和自进化各生成一份报告并统一查看。
- 在任务运行中关闭来源页，报告最终仍能完成或失败。
- 报告详情可返回正确对象，继续研究只传报告标识。
- 列表、详情、来源页的状态与时间一致。

## 8. 范围外

- 公开 URL 分享、多人评论、在线协同编辑。
- 复杂 PDF/Word 模板和批量导出；需要时另立 PRD。
