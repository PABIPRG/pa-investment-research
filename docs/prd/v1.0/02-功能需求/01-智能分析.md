# 智能分析

> 需求前缀：`ANA`

## 1. 产品目标

把个股、组合、市场简报和历史决策复盘统一为可跟踪的分析任务，并将完成结果沉淀为报告，而不是只留在一次对话里。

## 2. 分析类型

| 类型 | 关键输入 | 结果 |
|---|---|---|
| 个股多智能体分析 | 证券、研究深度 | 个股分析报告 |
| 持仓风险分析 | 当前组合版本、分析模式 | 组合风险报告 |
| 市场简报 | 盘前、盘中或盘后 | 市场简报报告 |
| 历史决策回测 | 可选证券、前瞻窗口 | 历史回测报告 |

## 3. 功能需求

| ID | 要求 | 级别 |

| ANA-001 | 股票代码输入只属于个股分析，不与全局搜索等输入共享状态 | P0 |

## 4. 任务交互

- 提交后按钮进入忙碌态并防止重复创建，不锁死其他分析卡片。
- 页面关闭或切换不取消后端任务。
- 前台等待达到上限后提示“仍在后台处理”，并提供报告中心入口。
- 失败原因必须可理解；可重试时创建新任务，不覆盖旧失败记录。

## 5. 校验

- A 股代码按后端证券主数据校验；不靠前端正则判断证券是否真实存在。
- 持仓为空时禁止发起持仓分析，并引导到我的投研。
- 前瞻窗口必须来自受控选项，不接受任意路径或后端参数。
- 模型未配置时，不影响已完成报告查看和不依赖模型的页面能力。

## 6. 验收

- 两个股票输入同时存在时，修改其中一个不会影响另一个。
- 四类任务可并行或先后运行，状态互不覆盖。
- 完成任务均存在唯一报告记录，报告能返回来源任务。
- 模型上下文不以 JSON 出现在共享输入框。
- 进入智能分析后首屏可见四类结构化任务；聊天历史不作为页面主体。
- 打开、展开、收起或关闭助理后，任务参数、进度、报告入口和滚动位置保持不变。
- “开始分析”启动真实任务；只有“让助理解读/进入会话”打开助理。

## 7. 范围外

- 1.0 不允许用户上传并执行任意分析代码。
- 1.0 不承诺任务级强制取消。
