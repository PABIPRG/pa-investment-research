## 版本结论

0.1.0-rc.9 将实时盯盘从“列表后方堆叠详情”调整为“显式选股后打开固定右侧悬浮研究窗”。首次进入页面不自动选择榜首证券，也不自动发起 K 线冷请求。用户可直接在榜单项上查看详情或带入智能分析，不再为了找到操作和详情跨越整份榜单滚动。

证券详情与 AI 研究助理共用右侧悬浮区域并互斥显示。悬浮研究窗支持最小化、标准和近全屏三种展示状态，固定在右侧且不可拖动；窄屏自动切换为近全屏覆盖层。研究内容中的行情、技术信号和资讯独立加载，个股资讯与当前证券绑定，全市场快讯通过独立标签明确区分。

本版本同时修复三类影响可用性的后端问题：指数非有限数值导致的响应失败、市场扫描上游断连后的错误语义和缓存回退、北交所代码被错误映射到沪市导致的 K 线冷请求失败。外部数据源不稳定时，系统优先展示带时间戳的最近成功数据；只有后台确认当前数据不可用后，才显示局部错误。
