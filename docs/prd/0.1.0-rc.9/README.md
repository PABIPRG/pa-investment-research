## 版本结论

0.1.0-rc.9 将实时盯盘从“列表后方堆叠详情”调整为“宽屏扫描与市场资讯双栏、显式选股后在视口右侧打开悬浮研究窗”。首次进入页面不自动选择榜首证券，也不自动发起 K 线冷请求。用户点击紧凑扫描行即可查看详情，或通过行内独立入口带入智能分析，不再为了找到操作和详情跨越整份榜单滚动。

宽屏下，市场资讯是独立的右栏内容，不属于个股详情。证券详情的标准状态 portal 到页面 `body`，相对视口右侧固定悬浮，宽度参考市场资讯栏并尽量不遮挡左侧扫描列表；用户主动放大后才进入近全屏。证券详情与 AI 研究助理互斥显示，固定且不可拖动；窄屏保持近全屏覆盖层。研究内容中的行情、技术信号和个股资讯独立加载，全市场快讯由右栏独立加载。研究窗与 AI 助理使用同一套展开/收起图标和交互语义。

本版本同时修复三类影响可用性的后端问题：指数非有限数值导致的响应失败、市场扫描上游断连后的错误语义和缓存回退、北交所代码被错误映射到沪市导致的 K 线冷请求失败。外部数据源不稳定时，系统优先展示带时间戳的最近成功数据；只有后台确认当前数据不可用后，才显示局部错误。
