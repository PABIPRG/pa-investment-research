# 风险中心

## 1. 风险来源与排序

风险中心聚合组合风险、影子策略、市场事件和风险画像四类来源。预警首先按高、中、低严重程度排序，同等级再按最近触发时间倒序。每条预警展示来源、关联标的、关联策略和有效性。

## `RISK-001` 历史、状态与重复触发（P1）

风险预警从临时计算结果升级为可追踪记录。处理状态包括：待处理、处理中、已处理、已失效。每条记录至少保存：预警编号、稳定去重键、首次发生时间、最近触发时间、触发次数、状态更新时间、开始处理时间、处理完成时间、失效时间、来源、等级、关联标的或策略、处理说明。

同一风险持续出现时，按稳定去重键更新最近触发时间、触发次数、当前等级和关联对象，不重复生成大量预警。已处理风险再次触发时重新进入待处理并保留上次处理历史；风险条件不再成立时可转为已失效，不能物理删除历史。

状态规则：

- 待处理 → 处理中：记录开始处理时间。
- 处理中 → 已处理：记录完成时间和处理说明。
- 待处理/处理中/已处理 → 已失效：记录失效时间。
- 已处理/已失效后再次触发：恢复为待处理并增加触发次数，历史时间节点保留。

验收条件：重复生成同一风险只更新一条记录；状态变更具有时间和说明；刷新或重启不丢失；四类来源使用同一历史查询体验。

## `RISK-002` 多维筛选（P1）

风险中心支持按以下条件组合筛选：时间范围、风险等级、预警来源、处理状态、是否仍然有效。筛选条件可清空，结果数量与当前条件一致；无结果时显示准确空状态。

验收条件：组合筛选采用交集语义；时间范围口径明确；更改状态后当前列表立即更新；筛选失败不清空已加载结果，并提供重试。
