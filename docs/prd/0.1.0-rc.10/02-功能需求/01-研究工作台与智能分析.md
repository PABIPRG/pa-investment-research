# 研究工作台与智能分析

## 1. 研究工作台

### `WORK-001` 业务分区（P1）

研究工作台首屏按三个业务模块组织，并使用醒目标题：

1. 持仓情况：持仓数量、成本、当前市值及进入完整持仓的入口。
2. 投资画像：投资风格、集中度、风险承受能力及风险测评入口。
3. 风险与资讯：风险预警、关联事件及进入风险中心的入口。

风险测评完成后刷新用户风险画像及依赖画像的预算信息。局部数据失败只影响所属模块，其他模块继续可用。

验收条件：三个模块在首屏具有清晰层级；相同信息不在多个无差别卡片中重复；保存风险测评后无需重新启动应用即可看到更新结果。

### `WORK-002` “我的投研”选择语义（P1）

“我的投研”输入区提供两个可选上下文：研究模块和标的，不再提供策略池策略选择。研究模块与“智能分析”页面使用同一目录，首期包括个股多智能体分析、持仓风险分析、历史决策回测和市场简报。用户可以选择“不指定模块”，也可以不选择具体标的，直接提出开放式研究问题。选择模块只改变助理的研究能力与提示上下文，不得被实现为选择策略池策略、预设或静态策略副本。

验收条件：输入区显示“选模块”和“选标的”，不显示“选策略”；四个模块名称与“智能分析”一致；清空任一选择不清空其他选择；不指定模块和标的时仍可发送问题；选择标的时清除旧版会话遗留的策略上下文；刷新或切换会话后按既有会话持久化规则恢复标的。

### `WORK-003` 清理重复入口（P1）

全局导航、顶部操作和“我的投研”内不得同时出现含义重叠的“投研资料”“投研报告”入口。保留入口必须名称唯一、去向明确：资料用于研究上下文与持仓等事实，报告用于已完成任务的正式产出。

验收条件：同一页面不存在两个名称相同但去向不同的入口；资料与报告的标题、说明和空状态可以让用户直接区分。

### `WORK-004` 偏好复盘入口归位（P1）

研究工作台页头右上角操作区提供“偏好复盘”入口，复用既有本地行为分析、兴趣洞察、漏斗、最近活动、暂停、恢复、清空和导出能力。进入后返回研究工作台，不再从“我的投研”的投研资料或组合概览提供重复入口。

验收条件：研究工作台首屏可进入偏好复盘；返回动作回到研究工作台；“我的投研”资料区不存在第二个偏好复盘按钮；既有 7/30 天复盘、隐私边界和用户控制能力不回退。

## 2. 智能分析

### `AI-001` 能力介绍定位（P0）

智能分析只展示研究专家或分析工具的介绍卡片，不直接承载完整分析表单、运行进度或最终结果。已有直接任务能力迁移到对应业务页面或由 AI 助理发起；正式结果统一进入投研报告。

验收条件：智能分析卡片只包含名称、摘要、能力范围、数据来源提示、查看详情和打开助理；页面不存在“运行回测”“开始个股分析”等直接执行按钮。

### `AI-002` 模块详情与打开助理（P0）

可选择的研究模块统一为：个股多智能体分析、持仓风险分析、历史决策回测、市场简报。“智能分析”和“我的投研 / AI 对话”从同一模块目录读取名称、数量、说明、助理模块和默认提示。详情可以展示模块内部的协作专家角色，但内部角色不作为输入区的独立模块选项。其他业务页面可以继续使用原研究专家选择器，但不得与“我的投研”的研究模块选择混为一谈。

统一交互链路：

```text
分析模块介绍卡
→ 查看详情
→ 打开助理
→ 进入“我的投研 / AI 对话”
→ 自动选择对应研究模块
```

验收条件：四个模块逐一跳转均自动选择正确模块并应用对应默认提示；不会错误选择策略池策略、标的或预设；返回智能分析后原卡片位置保持；模块目录增删时两处列表同步变化；用户已经编辑的对话草稿不得被模块切换覆盖。
