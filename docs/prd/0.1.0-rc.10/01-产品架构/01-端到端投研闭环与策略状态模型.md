# 端到端投研闭环与策略状态模型

## 1. 产品闭环

rc.10 以策略为主要证据载体，将研究入口与验证任务连接起来：

```text
持仓 / 画像 / 行情 / 事件
          ↓
研究专家协同分析
          ↓
事件假设通过用户确认或自动闭环写入策略池
          ↓
candidate ──首次自动回测──→ active
                                  ↓
                       真实行情 + 虚拟资金
                                  ↓
                         影子验证证据累计
                                  ↓
                 升级 / 观察 / 淘汰 / 变异回流
```

进入策略池的时点是策略记录首次成功写入且状态成为 `candidate`，不是回测完成、人工确认或开始影子验证。

## 2. 三个相互独立的状态维度

### 2.1 参与状态

| 状态 | 含义 | 推荐 | 自动复测 | 影子验证 |
|---|---|---:|---:|---:|
| `candidate` | 已入池，等待首次回测完成 | 否 | 首次任务 | 否 |
| `active` | 继续参与验证闭环 | 是 | 是 | 是 |
| `watch` | 观察中，停止推荐但继续积累证据 | 否 | 是 | 是 |
| `retired` | 已淘汰或已退役 | 否 | 否 | 否 |
| `rejected` | 明确不再参与 | 否 | 否 | 否 |
| `archived` | 用户归档，仅保留历史 | 否 | 否 | 否 |

首次回测任务成功完成后，系统自动将 `candidate` 转为 `active`，不设置人工确认。`active` 只表示继续参与回测、影子验证和自进化，不表示回测结论通过。首次任务若因系统或数据错误执行失败，策略仍为 `candidate` 并等待重试。

### 2.2 回测任务状态与验证结论

回测任务执行状态使用 `pending/running/completed/failed/cancelled`；验证结论另存为 `verification_status=passed/not_passed/insufficient`。只有执行状态为 `completed` 的任务才具有验证结论并完成首次回测。`not_passed` 和 `insufficient` 不自动阻止影子验证；执行失败或取消的首次任务不推进策略状态。只有参与状态明确变为 `retired/rejected/archived` 才退出后续流程。

### 2.3 置信层级与来源

- `tier=1`：普通参与策略。
- `tier=2`：对用户展示“已升级”。
- `watch`：对用户展示“观察中”。
- `retired`：按场景展示“已淘汰”或“已退役”。
- 变异是策略来源，不是参与状态；变异策略仍从 `candidate` 开始。

## 3. 自进化规则

每条策略至少积累五个不同的有效交易日影子数据后，才执行升降级、淘汰和变异：

| 条件 | 动作 |
|---|---|
| 影子净值不低于 `1.03` | 升级为 `tier=2` 高置信策略 |
| 影子净值不高于 `0.95` | 进入 `watch`，停止推荐并继续影子验证 |
| 影子净值不高于 `0.90` | 进入 `retired`，停止推荐、复测和影子验证 |
| 至少三笔平仓且胜率低于 `35%` | 进入 `retired` |
| 升级且样本外证据满足变异条件 | 允许生成变异候选并回流策略池 |

变异冷却期为七个自然日。同一母策略在冷却期内不得重复生成同一变异；回流候选必须重新经历首次回测。观察策略达到升级条件时可以恢复为参与中的高置信策略；达到淘汰条件时直接淘汰。

## 4. 任务与证据关系

回测任务、影子验证任务和报告是不同对象：

- 任务记录“谁、何时、为什么运行、运行到哪一步、成功或失败”。
- 回测结果记录该任务在指定历史窗口内的指标和结论。
- 影子证据记录真实交易日的纸面持仓、权益和净值。
- 报告是成功任务的可阅读产出，不能替代失败任务或运行中任务记录。

任何“最近一次摘要”都必须可以跳转到对应历史任务；删除或覆盖最近摘要不得破坏历史追溯。

## 5. 失败与并发原则

- 同一策略同一任务类型只能有一个待运行或运行中的自动任务。
- 自动任务失败必须留痕并允许后续重试，不能假装从未创建。
- 单策略失败不拖垮同批其他策略；批量任务保留逐策略结果。
- 归档、淘汰或拒绝发生后，不再新建自动回测或影子任务；已经运行的任务按安全终止或完成并留痕。
- 任何任务都不得触发真实交易。
