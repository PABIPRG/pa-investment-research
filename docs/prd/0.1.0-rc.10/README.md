## 版本结论

0.1.0-rc.10 不再以逐页增加功能为目标，而是把用户画像、实时行情、AI 研究、策略形成、回测、影子验证和自动进化连接成可解释、可追踪、可演示的完整投研闭环。

本版本统一三项关键产品语义。第一，智能分析是研究专家和工具的能力入口，完整研究由 AI 对话或对应业务页面承接。第二，策略进入候选池后自动完成首次回测；回测结论与是否继续参与闭环分离，不再设置“人工确认生效”。第三，回测和影子验证都以持久化任务历史留痕，最近一次摘要不能替代历史任务记录。

系统继续坚持研究与交易隔离：影子验证只使用真实行情和虚拟资金；任何研究、回测、自进化或演示流程都不得触发真实交易。

## 版本门禁

所有 P0 必须完成实现和范围匹配的自动化验证；P1 必须完成产品可见能力，或按需求中明确允许的降级形态交付。演示环境必须完成浅色模式、AI 让位布局、自动闭环开关、最近五个交易日影子数据、回测与影子历史、产业链权重标识和端到端演示脚本的逐项检查。

若仍需人工确认策略生效、回测或影子任务无法追溯、默认关系权重会被误解为披露占比、AI 面板遮挡实时盯盘核心行情，或者演示数据不足以触发自进化判定，则不得发布 rc.10。
