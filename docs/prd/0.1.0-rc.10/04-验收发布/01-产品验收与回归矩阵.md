# 产品验收与回归矩阵

## 1. P0 端到端验收

| 场景 | 操作 | 预期结果 |
|---|---|---|
| RC10-E2E-01 | 从智能分析依次打开四个分析模块 | 进入 AI 对话并自动选择对应模块及默认提示，不选择策略池策略或预设 |
| RC10-E2E-02 | 检查智能分析卡片 | 只有介绍、详情和打开助理，没有直接任务执行与完整结果 |
| RC10-E2E-03 | 宽屏实时盯盘打开 AI | 行情与榜单为右侧 AI 让位，核心指数和行情不被覆盖 |
| RC10-E2E-04 | 中等宽度打开 AI | 次级字段按规则压缩，核心行情仍完整可读 |
| RC10-E2E-05 | 窄屏打开并关闭 AI | 自动近全屏；关闭后滚动、扫描类型、证券和焦点恢复 |
| RC10-E2E-06 | 从事件确认假设入池 | 策略立即以 `candidate` 入池并自动创建首次两年回测 |
| RC10-E2E-07 | 自动事件生成候选 | 与用户确认路径使用相同入池和首次回测规则，重复事件幂等 |
| RC10-E2E-08 | 首次任务成功完成，验证结论分别为通过、未通过、样本不足 | 三者都自动成为参与中的 `active`，无人工确认入口；任务执行失败或取消不推进状态 |
| RC10-E2E-09 | 连续运行多次手动和自动回测 | 每次任务独立留痕，窗口、来源、时间、结果和失败原因可查 |
| RC10-E2E-10 | 在第 14、15、16 天执行复测巡检 | 第 14 天不建；满 15 天只建一个；第 16 天不重复建；参与中但验证未通过的策略按产品设计排除，不进入自动复测 |
| RC10-E2E-11 | 对归档、淘汰、拒绝策略巡检 | 不创建新自动回测任务 |
| RC10-E2E-12 | 对不同验证结论的参与中策略运行影子验证 | 均可运行；首次任务未成功完成或已退出策略被准确阻止 |
| RC10-E2E-13 | 运行单策略和批量影子验证 | 总任务和逐策略结果均留痕，局部失败不丢失其他结果 |
| RC10-E2E-14 | 查看最近、单策略和全部影子历史 | 三种视图范围准确，任务、净值证据和报告可互相定位 |
| RC10-E2E-15 | 重启服务后查询任务 | 回测和影子成功、失败及中断状态仍可追溯 |
| RC10-E2E-16 | 加载最近五个交易日演示数据 | 自进化门槛满足并展示正常、升级、观察/淘汰和变异证据 |
| RC10-E2E-17 | 按演示脚本完整走查 | 从画像持仓到变异回流无断链，自动闭环状态明确 |

## 3. 分层验证

| 层级 | 必测内容 |
|---|---|
| 后端单元 | 策略状态转换、首次任务幂等、15 天边界、任务持久化、五交易日门槛、关系来源 |
| 后端合同 | 回测与影子任务列表/详情、逐策略结果、事件受限降级契约、产业链来源字段 |
| 调度 | 自动闭环开关、错过计划补建、并发巡检幂等、退出策略排除 |
| 前端组件 | 专家跳转、工作台分区、帮助入口、回测管理、影子历史、状态映射、筛选与空错态 |
| Shell 集成 | AI 受控让位、证券研究互斥、返回路径、滚动与焦点恢复、其他页面悬浮模式回归 |
| 数据迁移 | 旧策略最近回测和旧影子净值的兼容读取，不伪造缺失历史 |
| GUI | 浅色模式优先；宽屏、窄桌面、移动端；长名称、无数据、失败和部分成功 |
| 演示 | 五交易日数据生成与清理、环境开关检查、端到端脚本彩排 |

## 4. 兼容回归

- rc.9 的实时盯盘扫描、市场资讯、证券悬浮研究窗、个股资讯和行情失败恢复不得回退。
- 既有投研报告可继续读取；新增任务历史不改变旧报告编号。
- 旧策略缺少任务历史时显示“历史未留存”，不得把最近回测复制成多条历史。
- 旧影子净值仍可作为证据读取，但不得被描述为完整任务历史。
- 风险画像和风险等级不因本版本的界面重组而被降低。
- 深色模式不作为 rc.10 专项范围，但不能出现阻断操作的严重回归。
