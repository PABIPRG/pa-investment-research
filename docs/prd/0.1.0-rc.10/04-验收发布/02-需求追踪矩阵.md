# 需求追踪矩阵

## 1. 追踪规则

rc.10 的设计、实现、测试、演示和验收必须引用本矩阵中的稳定编号。当前矩阵描述产品责任边界，不把计划实现位置写成已完成事实。需求完成后补充实际实现文件、自动化命令和真实页面证据。

## 4. 横切映射

| 需求 | 约束 | 主要验证 |
|---|---|---|
| `NF-001` | 现状与目标分离 | PRD、计划、验收记录状态审查 |

| `NF-007` | 交易隔离 | 不创建真实订单的直接负面保证 |
