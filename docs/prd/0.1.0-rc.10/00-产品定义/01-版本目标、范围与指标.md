# 版本目标、范围与指标

## 1. 问题定义

现有产品已经具备持仓、风险画像、实时盯盘、研究专家、策略回测、影子验证、自进化、产业链和风险预警等能力，但用户仍难以沿一条连续路径完成研究。部分入口重复或名称与实际能力不一致；实时盯盘打开 AI 后核心行情被覆盖；策略生命周期仍混有人工确认；策略回测和影子验证只强调最近结果，缺少完整历史；产业链默认权重可能被误读为真实占比；风险预警缺少可追踪的处理状态。

下周演示需要突出产品创新和投研闭环，而不是逐页罗列功能。因此 rc.10 的核心问题是：让每一步都有明确入口、稳定状态、历史证据和下一步动作，并能在浅色模式下可靠演示端到端闭环。

## 2. 版本目标

### 2.1 P0 目标

- `AI-001`：将智能分析收敛为研究专家和分析工具的能力介绍区，不在该页面直接承载完整任务结果。
- `AI-002`：专家介绍、详情和“打开助理”形成统一链路，打开后自动选择对应研究专家。
- `WATCH-027`：压缩实时盯盘纵向密度，移除两行非必要提示，打开 AI 后核心行情仍完整可见。
- `WATCH-028`：实时盯盘使用 AI 受控让位布局，宽屏并列、空间不足时压缩、窄屏近全屏。
- `STRAT-001`：降低策略生命周期说明层级，移除页面级全局回测窗口和刷新区，使策略列表成为视觉重点。
- `STRAT-002`：删除“人工确认生效”步骤；首次回测任务成功完成后自动进入可参与影子验证的 `active` 状态，验证结论不作为准入条件。
- `BT-001`：建立独立策略回测任务历史，完整记录手动和自动回测。
- `BT-002`：提供回测管理、新建任务、最近状态和历史列表。
- `BT-003`：策略首次入池后自动创建默认两年窗口的首次回测。
- `BT-004`：按最近一次回测完成时间执行 15 天自动复测。
- `SHADOW-001`：完成首次回测的参与中策略可以运行影子验证，不要求回测结论为通过。
- `SHADOW-002`：建立影子验证任务历史，支持最近摘要、单策略历史和全量历史。
- `SHADOW-003`：支持单策略与符合条件策略的批量运行，并继续提供纸面持仓、净值和报告入口。
- `DEMO-001`：演示环境具备最近五个交易日的影子验证数据，可完整触发自进化展示。
- `DEMO-002`：形成可重复执行的端到端演示主线、操作脚本和演示前检查表。

### 2.2 P1 目标

- `WORK-001`：研究工作台按持仓情况、投资画像、风险与资讯重新分区。
- `WORK-002`：“我的投研”统一标的、策略和专家的标题与选择语义，并允许无具体标的的开放式研究。
- `WORK-003`：清理重复的投研资料、投研报告及含义重叠入口。
- `EVO-001`：统一正常、观察、升级、淘汰和变异来源的用户文案。
- `EVO-002`：将闭环运行状态和策略衍生关系上移为首屏紧凑看板。
- `CHAIN-001`：区分披露占比、默认关系权重和推断关系，默认值不得冒充真实占比。
- `CHAIN-002`：切换中心企业后重新定中心加载，默认三层并提供层级控制、颜色图例和方向说明。
- `IMPACT-001`：为事件传导提供分页或明确的有界结果降级，并支持稳定增量加载状态。
- `RISK-001`：建立风险预警历史、处理状态、时间节点和重复触发合并规则。
- `RISK-002`：支持按时间、等级、来源、状态和有效性组合筛选。

## 3. 目标用户与核心任务

主要用户是需要在盘中发现机会、形成研究结论并持续验证策略的个人投资者。核心任务不是完成单次分析，而是沿以下闭环持续积累证据：

```text
用户画像与持仓
→ 实时行情和事件发现
→ AI 研究专家协同分析
→ 事件形成策略假设
→ 策略入池并自动回测
→ 回测历史追踪
→ 影子验证及历史追踪
→ 自动升降级、淘汰和策略变异
→ 回流策略池
```

## 4. 版本范围

### 4.1 纳入范围

- 会议确认的全部 P0、P1 产品需求。
- rc.9 实时盯盘、悬浮证券研究窗和行情失败恢复能力的兼容回归。
- 策略回测、影子验证、风险预警的持久化历史与查询体验。
- 演示环境所需的配置检查、测试数据和操作脚本。

### 4.2 不在本版本范围

- 深色模式专项重做；它保留为 P2 后续事项，rc.10 只要求不发生阻断性回归。
- 任意拖动或自由调整 AI、证券研究面板的尺寸和位置。
- 真实交易、实盘委托、自动下单或真实资金接入。
- 以演示测试数据冒充真实投资业绩。
- 无上游分页能力时在前端伪造无限滚动或虚构总数。

## 5. 成功指标

| 指标 | rc.10 目标 | 说明 |
|---|---:|---|
| 智能分析到目标专家自动选择正确率 | 100% | 不误选策略、预设或其他专家 |
| 打开 AI 后实时盯盘核心行情可见率 | 100% | 基准宽屏与窄桌面均满足 |
| 仍需人工确认生效的策略数 | 0 | 首次回测任务成功完成后自动进入参与状态 |
| 回测任务历史留痕率 | 100% | 手动、首次自动和 15 天复测统一记录 |
| 影子任务历史留痕率 | 100% | 单策略与批量、成功与失败均可追溯 |
| 满 15 天重复创建异常任务数 | 0 | 同策略同轮只有一个待运行或运行中任务 |
| 默认权重冒充披露占比数 | 0 | 默认和推断关系有明确标识 |
| 重复风险生成新预警的比例 | 0 | 同一去重键更新原记录和触发次数 |
| 演示闭环完成率 | 100% | 脚本从画像与行情走到变异回流 |
| 真实交易指令数 | 0 | 所有验证仅研究和纸面记账 |

## 6. 发布判定

全部 P0 和 P1 验收场景通过后方可发布。若某项 P1 因上游能力限制只能降级，必须满足该需求明确规定的降级体验、限制说明和无伪造原则，并记录为已知边界。演示环境检查不替代产品验收，但任何演示阻断项未解决都不得标记为“演示就绪”。
