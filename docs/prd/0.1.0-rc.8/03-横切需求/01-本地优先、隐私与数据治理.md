# 本地优先、隐私与数据治理

## 1. 数据驻留

### `DG-001` 本地唯一事实源

本地学习事实与现有本地行为存储共用同一权威数据源，不在浏览器本地存储、日志或第二份缓存中复制原始事件。内存可保存短期去重键，但进程退出后无需恢复。

### `DG-002` 外部后端隔离

本地学习事件、反馈、设置、清空和复盘只能访问应用拥有或附着的本地运行时。若当前配置指向外部后端，客户端主机必须在网络请求前拒绝操作；仅依赖远端返回错误不满足要求。

## 2. 数据最小化

### `DG-003` 固定白名单

事件协议采用动作、表面、目标类型和上下文四层白名单。上下文只允许归一化证券代码、行业标识、策略标识、事件类型、方向、风险来源、风险严重度、分析类型、位置和原因码等有限字段。

以下内容不得通过事件或反馈元数据落盘：搜索原文、卡片标题或正文、报告正文、聊天内容、提示词、URL、文件路径、API 密钥、账户标识、持仓数量、成本、交易金额以及任意未声明字段。

### `DG-004` 服务端权威时间

服务端生成写入时间并限制客户端事件标识和会话标识的长度。客户端时间仅可用于非权威显示且 0.1.0-rc.8 不落盘，避免伪造时间影响保留和复盘。

## 3. 保留与删除

### `DG-005` 双重保留

本地行为按时间和数量双重限制，默认保留 90 天且不超过 2,000 条有效记录；任一上限先到即触发裁剪。设置与显式风险资料不计入行为记录上限。

### `DG-006` 原子写入

事件批次和设置更新必须通过现有本地原子存储完成。并发写入不得产生损坏 JSON、部分事件或临时文件替代正式数据。

### `DG-007` 可验证清空

清空删除本地交互和内容反馈，保留持仓、显式风险资料、策略验证数据和研究成果。清空响应返回删除数量，复盘随后必须为空。

## 4. 推断与解释

### `DG-008` 确定性推断

偏好聚合使用带版本的确定性规则。规则按证据强度计权，结论必须携带样本量、覆盖天数、时间窗和置信度。缺少最小证据时不生成排行。

### `DG-009` 非敏感推断

系统只推断研究兴趣和使用偏好，不推断政治、宗教、健康、性取向、收入、净资产或其他敏感个人属性，也不从行为推断投资适当性等级。

## 5. 可靠性与性能

### `NF-001` 非阻断

事件记录是附属能力。超时、存储失败、协议拒绝或本地学习暂停均不得改变原业务操作结果。主动反馈可以提示失败，但不得隐藏或锁死内容。

### `NF-002` 有界资源

单次批量最多 50 条事件，单字段和标识长度受限，复盘仅扫描保留窗口内的有界数据。前端去重集合有容量上限，避免长会话内存无界增长。

### `NF-003` 可访问性与主题

复盘与反馈控件支持键盘操作、可见焦点、语义化状态和读屏标签，并使用现有主题令牌，不引入仅靠颜色表达的置信度或开关状态。

### `NF-004` 可测试性

安全负面保证必须由直接测试覆盖，包括未知元数据拒绝、外部后端零请求、风险严重度不降级、行为不修改显式风险和埋点故障不阻断业务。
