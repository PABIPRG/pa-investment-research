# 0.1.0-rc.8 验证报告

## 1. 验证结论

截至 2026 年 8 月 28 日，0.1.0-rc.8“本地学习与偏好复盘”的 PRD 范围已实现，功能链路、隐私边界和风险隔离具备直接自动化证据。后端全量回归、前端受影响链路、类型契约、完整构建、GUI 全量回归和投研 Web 原型回归均通过。

仓库级全量静态检查、文档同步和覆盖率任务仍受本分支未修改的既有问题影响，因此本报告将“功能验证通过”与“仓库基线未全绿”分开记录。交付只通过私仓特性分支与跨仓 PR 进入公仓，不直接推送 `public/master`。

## 2. 功能完成范围

- 建立单一本地行为事实源，使用服务端时间、严格白名单、幂等写入、90 天保留期和 2,000 条共享上限。
- 覆盖有效曝光、打开、带入分析、搜索结果选择、组合查看和显式反馈；自由文本、持仓数量与成本、URL、路径和未知字段不得进入记录。
- 在“我的投研”中提供 7 天与 30 天偏好复盘、证据数、置信度、行为漏斗、安全近期活动、暂停/恢复、二次确认清空和安全摘要导出。
- 保留旧行为数据的有限兼容读取，同时采用反馈最后值覆盖，避免纠正操作重复计权。
- 将行为学习限制在兴趣解释和非关键内容软排序；显式风险参数、关键预警严重度和策略生命周期均不受行为反馈直接控制。
- 主机运行时把本地学习与反馈操作限制为本地租约，在外部后端模式下于网络请求前拒绝，并保证附属记录失败不阻断原业务。

## 4. 安全与负面保证

| 保证 | 验证结论 |
|---|---|
| 敏感字段不得落盘 | 模式层严格拒绝未知字段和错误类型，服务层再次按事件类型白名单清洗；包含搜索词、标题、提示词、持仓、成本、URL 或路径的输入被拒绝 |
| 客户端不得伪造时间 | 存储时间统一由本地服务生成；客户端时间字段不在协议中 |
| 外部后端零埋点请求 | 本地操作在调用 `fetch` 前拒绝并释放租约；监听测试确认网络调用次数为零 |
| 埋点失败不阻断业务 | 记录器吞掉附属错误且使用有界去重缓存；打开、搜索、分析与组合查看保持原结果 |
| 行为不得修改显式风险 | 正负行为样本、旧记录和连续反馈均不能改变显式风险等级或有效风险参数 |
| 反馈不得降低关键预警 | 风险严重度、原因码和关键显示条件保持不变，反馈只进入归因 |
| 行为不得直接升降级策略 | 策略进化只消费真实组合结果与既定归因，交互事件不改变策略状态 |
| 保留与清空必须有界 | 写入、状态读取和复盘前统一执行时间与数量裁剪；清空只删除行为和反馈，保留持仓、风险资料与研究成果 |

## 5. 仓库级已知基线问题

以下问题已通过差异核对确认不在本轮修改范围内，不能把它们误报为本功能通过，也不应在本分支顺手修改：

1. 全量静态检查在 `packages/boot/app-boot/src/index.ts` 的既有重复函数规则处失败；本轮改动文件的独立严格检查通过。
2. 文档同步 28 个任务中 22 个通过，6 个失败，涉及既有 Cordis/客户端/配置目录漂移、既有导出注释欠账、行业链 README 模型格式和投研类型文档漂移；本轮新增双语文档、链接与格式检查全部通过。
3. 全量覆盖率任务实际运行了 877 个测试文件和 14,048 项测试。首次结果中的本功能主题令牌和临时工作树运行时路径问题已修复并分别复测通过；剩余失败集中在未修改的 hooks 超时波动和既有 Cordis 生成目录检查。新增模块已单独达到 100% 覆盖率。
4. 通用构建产物 Web 测试任务长时间无新增输出后被终止；投研静态 Web 原型 5 项、GUI 全量 3,939 项和完整构建均已通过，但这些证据不等同于真实构建态投研 E2E，因此对应发布检查项保持未勾选。

这些基线问题应在进入公共仓库前单独治理或由仓库维护者确认接受，不影响本版本安全边界和核心交互的验证结论。
