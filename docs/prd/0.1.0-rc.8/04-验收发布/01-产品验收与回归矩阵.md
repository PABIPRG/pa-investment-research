## 2. 分层验证

| 层级 | 必测内容 |
|---|---|
| 后端单元 | 白名单、服务端时间、批量上限、去重、保留、暂停、清空、确定性聚合、反馈覆盖 |
| 后端回归 | 个性化画像不修改显式风险；风险反馈不降低严重度；既有卡片、策略、归因接口兼容 |
| 主机运行时 | 操作路由、请求体校验、外部后端前置拒绝、租约释放、错误透传 |
| 前端单元 | 会话与短窗去重、失败吞吐、有界缓存、无敏感字段构造 |
| 组件测试 | 复盘时间窗、空态、暂停/恢复、清空确认、反馈纠正、加载和失败状态 |
| GUI | 深浅主题、窄宽视口、键盘焦点、中文溢出、卡片反馈和复盘布局 |
| Web 组装 | 真实构建产物中的“我的投研→偏好复盘”路径、关键交互和无密钥降级 |
| 全量回归 | 后端测试、前端类型检查、静态检查、覆盖率、构建、文档同步与现有 Web 快照 |

## 3. 安全验收

- 构造包含 `query`、`title`、`prompt`、`holdings`、`cost`、`url`、`path` 或任意未知键的事件，验证其在落盘前被拒绝且正式存储无残留。
- 构造外部后端租约并监听网络调用，验证本地学习和反馈操作直接拒绝、释放租约且不调用 `fetch`。
- 构造连续负向风险反馈，验证风险严重度、标题、原因码和关键显示条件不变。
- 构造大量负面资讯点击，验证显式风险等级和有效风险参数不变。
- 构造超过 90 天和超过 2,000 条记录，验证双重保留后复盘只使用有效窗口。

## 4. 兼容与降级

旧版 `behavior.json` 中的浏览和反馈记录应能继续用于有限的兴趣聚合；缺失新字段时按旧协议安全解析，不进行风险推断。升级不执行破坏性迁移，新事件使用协议版本区分。

偏好复盘接口不可用时显示局部错误和重试，其他页面维持既有功能。事件记录被暂停或拒绝时，系统不重试形成请求风暴。清空失败必须保留当前页面数据和确认结果，避免误报已删除。
