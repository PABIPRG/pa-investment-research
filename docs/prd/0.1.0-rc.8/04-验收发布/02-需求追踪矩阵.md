# 需求追踪矩阵

## 1. 追踪规则

实现、自动化测试和验收记录必须引用本矩阵中的稳定需求编号。新增范围先更新对应产品需求，再扩展设计与测试；代码存在但没有需求编号的能力不计入 0.1.0-rc.8 完成范围。

## 2. 需求映射

| 需求 | 设计责任 | 主要实现位置 | 主要验证 |
|---|---|---|---|
| `LL-001` | 事件协议与本地写入 | 后端本地学习模块、运行时操作映射 | 协议白名单与批量写入测试 |
| `LL-002` | 视口观测与会话去重 | 前端记录器、研究工作台卡片 | 计时、阈值与重复挂载测试 |
| `LL-003` | 主动交互适配 | 搜索、卡片、分析入口 | 失败非阻断与敏感字段缺席测试 |
| `LL-004` | 最后值反馈模型 | 反馈接口、卡片反馈控件 | 纠正、失败、风险不降级测试 |
| `PR-001` | “我的投研”内二级页面 | 组合页、偏好复盘页 | 路由与返回组件测试、Web 组装回归 |
