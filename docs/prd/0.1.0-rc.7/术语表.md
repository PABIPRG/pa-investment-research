# 术语表

| 术语 | 0.1.0-rc.7 定义 |
|---|---|
| 研究工作台 | 产品总览入口，聚合信息但不替代业务页面 |
| 一级业务入口 | 智能分析、实时盯盘、策略研究、自进化、我的投研、产业链之一 |
| 业务能力 | 六个一级业务入口及策略研究内部的影子验证，共七项可追踪能力 |
| 投研助理 | 复用正式会话能力的全局自然语言研究浮层，不占用智能分析页面，也不拥有业务事实 |
| 助理停靠态 | 投研助理固定在业务页右侧的浮窗状态，业务路由和页面状态保持不变 |
| 助理展开态 | 投研助理以具名模态框覆盖大部分界面的状态，可收起回停靠态 |
| 投研报告 | 异步研究任务形成的持久、可再次打开、可追溯成果 |
| 统一上下文 | 模型按需通过受控工具读取的后端事实集合，不是输入框 JSON |
| 业务对象标识 | 后端签发、可校验的不透明 ID；页面不得拼接任意路径 |
| 影子验证 | 策略研究内不产生真实委托的纸面运行、持仓与净值记录子流程 |
| 策略验证分类 | 由最新有效证据派生的已验证通过、未验证、验证未通过或已归档，只读且不等于生命周期状态 |
| 自进化 | 基于影子归因生成策略调整预案，并经用户确认后应用的流程 |
| 风险画像 | KYC、行为和规则共同形成的风险偏好与预算事实 |
| 工作区 | 正式会话与本机存储的组织边界；不是投研业务域 |
| 直接数据页 | 不依赖模型生成即可读取或操作真实后端数据的页面 |
| 前台超时 | 页面停止等待的体验状态，不代表后端任务已经失败 |
| 真实数据 | 来自已接入后端或明确标注的外部来源；不包括为填充 UI 生成的模拟值 |
| 高影响动作 | 改变策略、风险画像、持仓或其他持久业务状态的动作 |
| 1+6/7 | 研究工作台加 6 个一级业务入口，承载 7 项业务能力；报告、助理和设置属于全局能力 |
