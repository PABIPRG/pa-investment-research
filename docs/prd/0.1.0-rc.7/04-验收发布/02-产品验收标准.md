# 产品验收标准

## 1. 发布阻断原则

以下任一情况存在，0.1.0-rc.7 不得发布：

- 任何一级业务域不可进入或展示错误页面。
- 成功任务没有统一报告入口。
- 输入框出现系统业务 JSON。
- 新建对话残留旧消息、草稿、附件或晚到预填。
- 未确认即可改变策略、自进化或其他高影响状态。
- 工作区选择阻断主流程。
- 深色主题存在不可辨识 Hover、焦点或按钮文字。
- 后端缺失时使用模拟数据冒充真实结果。
- 影子数据被描述为真实账户结果。
- 智能分析被聊天欢迎页或消息时间线替代。
- 助理展开、收起或关闭导致业务路由、表单、筛选或任务状态丢失。
- 验证分类与策略生命周期状态混用，或把样本不足误判为验证未通过。

## 2. 信息架构验收

- [ ] 默认进入研究工作台。
- [ ] 6 个一级业务入口按既定分组一步可达，影子验证在策略研究内一步可达。
- [ ] 侧栏选中态与主标题始终一致。
- [ ] 投研报告、投研助理和设置拥有稳定全局入口。
- [ ] 左上和新建对话不突出工作区。
- [ ] 旧影子验证深链进入策略研究的影子验证视图，不恢复独立一级导航。

## 3. 研究闭环验收

- [ ] 实时盯盘线索可进入智能分析。
- [ ] 产业链公司或节点可进入智能分析。
- [ ] 成功分析可打开报告并进入策略研究。
- [ ] 策略激活后可保持选择切换到策略研究内的影子验证视图。
- [ ] 影子数据满足门槛后可进入自进化。
- [ ] 自进化先预览、再确认、后应用并形成审计和报告。
- [ ] 我的投研事实实际影响工作台、盯盘、分析和策略匹配。

## 4. 报告验收

- [ ] processing、completed、failed 三类状态可再次打开。
- [ ] 来源页与报告中心状态一致。
- [ ] 关闭来源页后后台结果仍能落入同一报告。
- [ ] 报告显示来源对象、数据时间、生成时间和风险性质。
- [ ] 报告可返回来源页并继续研究。

## 5. 助手与会话验收

- [ ] 智能分析首屏显示个股、持仓、简报、回测四类结构化任务，聊天不作为页面主体。
- [ ] AI 助理在关闭、右侧停靠、近全屏之间切换时，智能分析不卸载，表单值、滚动位置和任务进度保持不变。
- [ ] 6 个一级业务入口及影子验证视图中的助手入口均保留当前页面状态。
- [ ] 助理完成 `closed → docked → expanded → docked → closed`，业务路由、输入、筛选、滚动和任务不变。
- [ ] 展开态使用具名模态语义和焦点约束；`Escape` 先收起再关闭并归还焦点。
- [ ] 会话模块选择只影响工具范围，不修改业务表单或写入 JSON。
- [ ] 输入框只显示可读自然语言意图。
- [ ] 模型通过受控工具读取上下文，未知领域和非法标识被拒绝。
- [ ] 新建对话显示空白，异步预填竞态无串写。
- [ ] 无模型密钥时直接数据页仍可使用。

## 6. 风险、事件与策略详情验收

- [ ] 工作台和“我的投研”每条风险均可打开复用详情，展示原因、影响、阈值、来源、时间和建议。
- [ ] 风险缺失值显示“—/数据不足”，不伪造 `0`；带入分析不复制风险 JSON。
- [ ] “我的投研”事件列表覆盖加载、空、错、成功和重试。
- [ ] 无 `report_id` 的事件打开安全 Markdown “事件研究详情”；有 `report_id` 时可从报告中心再次打开。
- [ ] 事件身份不使用 `event_idx`，危险 HTML、脚本协议和任意本地路径不可执行。
- [ ] 策略池四类筛选互斥且数量完整，生命周期状态与验证分类同时可见。
- [ ] 样本不足、成交不足和运行中归为未验证；退役优先归为已归档。
- [ ] 每类策略均可打开详情，查看标签、逻辑、约束、验证摘要、来源和失败原因。

## 7. UX 验收

- [ ] 同层级按钮尺寸一致，加载时不跳动。
- [ ] 明暗主题全部状态矩阵通过。
- [ ] 键盘焦点、弹窗焦点归还和 Esc 行为正确。
- [ ] 1024/1280/1440px 无关键动作遮挡。
- [ ] 空、慢、失败、过期状态都能回答“发生了什么、还能做什么”。

## 8. 后端与启动验收

- [ ] 三套后端分别健康时核心数据可读。
- [ ] 任一后端关闭时只影响相关区域。
- [ ] 标准 Web 与 Electron 启动路径完成依赖校验和托管清理。
- [ ] macOS 原生模块准备发生在构建或依赖刷新之后。
- [ ] 启动卡点有阶段日志，退出后无本次拥有的孤儿进程。

## 9. 签署

产品、设计、前端、后端与测试分别确认本清单。任何豁免必须进入[变更与决策管理](../05-研发流程/02-变更与决策管理.md)，不能只写在聊天或 PR 评论中。
