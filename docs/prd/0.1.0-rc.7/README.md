## 需求级别

- `P0`：0.1.0-rc.7 发布阻断项，任一未满足均不得发布。
- `P1`：0.1.0-rc.7 应交付项；只有经产品变更评审才能延期。

## 统一结论

- 0.1.0-rc.7 的业务信息架构是“研究工作台 + 6 个一级业务入口、7 项业务能力”；影子验证并入策略研究，不再单列一级导航。
- “投研报告”和“投研助理”是全局能力，不计入 6 个一级业务入口。
- “智能分析”是结构化任务工作台；AI 对话以右侧停靠或近全屏浮窗增强当前业务页，不能替代智能分析。
- 确定性业务操作优先在结构化页面完成；助理负责解释、延伸研究和自然语言入口。
- 页面向模型传递意图和不透明对象标识；模型通过工具或 Skill 读取事实，输入框不得承载业务 JSON。
- 工作区只是一种本机存储边界，主流程不要求用户理解或选择它。
- 0.1.0-rc.7 不执行真实交易，不自动应用自进化动作，不用模拟数据冒充真实结果。
