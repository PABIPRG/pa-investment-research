# 用户场景与核心指标

## 1. 目标用户

### U1 自主研究型投资者

有明确自选和持仓，希望把行情、新闻、基本面与风险统一起来，但不希望维护复杂量化系统。

### U2 专业研究人员

需要快速发现异动、形成可复核假设、回看历史结论，并保留证据链供后续复盘。

### U3 策略实验者

希望把研究假设结构化，先通过回测和纸面账户观察，再决定是否调整策略，不接受黑盒自动写入。

## 2. 核心场景

| 场景 | 起点 | 完成定义 |
|---|---|---|
| 盘前准备 | 研究工作台 | 生成一份带数据时间和风险提示的盘前简报报告 |
| 盘中异动研究 | 实时盯盘 | 选择证券，完成分析并保存报告 |
| 产业线索研究 | 产业链 | 选择公司或节点，查看关系证据并进入分析 |
| 组合风险检查 | 我的投研 | 更新持仓后得到集中度、预算突破和建议动作 |
| 策略形成 | 分析报告或市场事件 | 形成候选策略，完成样本外回测并明确状态 |
| 纸面验证 | 活跃策略 | 完成当日幂等影子运行并刷新净值和持仓 |
| 策略复盘 | 自进化 | 查看归因和只读预案，确认或放弃变更 |
| 延伸研究 | 任一业务页或报告 | 助手通过工具读取当前事实并给出可追溯解释 |

## 3. 北极星指标

`周度有效研究闭环用户数`：一周内至少完成“发现或选择对象 → 生成报告 → 执行一个可追溯后续动作”的去重用户数。

后续动作包括：加入候选策略、运行回测、启动影子验证、完成组合风险复核或基于报告继续研究。

## 4. 0.1.0-rc.7 核心指标

| 类别 | 指标 | 0.1.0-rc.7 目标 |
|---|---|---|
| 可达性 | 1+7 一级入口可用率 | 100% |
| 成果沉淀 | 成功异步任务生成可打开报告的比例 | 100% |
| 连续性 | 报告进入下一业务动作无需重复录入的比例 | ≥ 95% |
| 稳定性 | 页面级未捕获错误会话占比 | < 0.5% |
| 诚实性 | 无真实数据时展示虚构业务数值 | 0 次 |
| 会话隔离 | 新建对话残留上一会话草稿或预填 | 0 次 |
| 上下文卫生 | 输入框出现系统生成业务 JSON | 0 次 |
| 高影响安全 | 未确认即应用策略/进化写入 | 0 次 |
| UX 一致性 | 发布回归中的主题与状态阻断缺陷 | 0 个 |

## 5. 漏斗指标

```text
有效线索 → 打开分析 → 分析完成 → 报告打开 → 后续动作 → 复盘
```

每一步记录来源模块、对象类型和匿名任务状态，不采集用户输入全文、持仓明细、模型密钥或报告正文作为产品分析事件。

## 6. 反指标

以下数字上升不代表产品成功：

- 模型消息数量或 token 消耗增加。
- 用户被迫反复生成同一报告。
- 因找不到结果而增加的页面往返。
- 自动生成但从未打开、从未形成后续动作的报告数量。
- 通过隐藏风险提示换来的按钮点击率。
