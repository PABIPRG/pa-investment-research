# 版本范围与基线差距

## 1. 经验证的产品基线

2026-08-26 已获取并运行 `public/master` 的 `03c78e42b6`。该基线已具备：

- “研究工作台 + 智能分析、实时盯盘、策略研究、影子验证、自进化、我的投研、产业链”的 `1+7` 导航。
- 三套受托管后端：`trading-core`、`market-watch`、`industry-chain`。
- 7 个业务页的真实结构化内容；实时盯盘和产业链可读取真实后端数据。
- 页面级独立加载、空状态、失败状态与部分重试能力。
- 投研 UI 基线测试 9 个文件、46 个用例通过。

以上是 0.1.0-rc.7 的起点，不代表已经达到产品级发布标准。

基线中的“影子验证”曾是独立一级导航；本轮按 [DEC-001](04-v0.0.2交互稿对齐与本轮增量.md) 合并为“策略研究”内部视图。基线中的“智能分析”若映射到会话页，按 [DEC-002](04-v0.0.2交互稿对齐与本轮增量.md) 恢复为结构化任务工作台。

## 2. 0.1.0-rc.7 P0 差距

| 编号 | 当前问题 | 0.1.0-rc.7 必须达到 |
|---|---|---|
| GAP-01 | 生成结果散落在任务页，缺少统一查看入口 | 提供持久的“投研报告”全局入口和详情页 |
| GAP-02 | 按钮尺寸、层级、Hover、深色主题状态仍不完全一致 | 建立统一组件状态矩阵并完成明暗主题回归 |
| GAP-03 | 助手把结构化业务快照序列化进输入框 | 输入框只显示自然语言意图，模型通过工具或 Skill 读取事实 |
| GAP-04 | 新建对话与异步预填存在旧草稿残留风险 | 新会话原子清空消息、草稿、附件和待写入预填 |
| GAP-05 | 多个股票输入可共享同一状态 | 全局搜索、分析、回测、盯盘、产业链输入相互独立 |
| GAP-06 | 工作区在左侧和空白会话中过度显性，并可能阻断输入 | 主流程隐藏工作区，只在设置中管理存储位置 |
| GAP-07 | macOS 生产构建后原生模块可能仍带 quarantine，启动卡死且无提示 | 标准启动路径自动准备原生模块并提供明确失败信息 |
| GAP-08 | 前台任务超时后缺乏统一可恢复归宿 | 后台完成结果继续进入报告中心，可按任务状态恢复 |
| GAP-09 | 智能分析被会话欢迎页取代，业务任务不够突出 | 恢复个股、持仓、简报、回测四类结构化任务，助理独立浮层呈现 |
| GAP-10 | 影子验证与策略研究割裂，策略验证状态难以总览 | 合并为同一页面的策略池与影子验证视图，并提供四类验证归档 |
| GAP-11 | 风险、事件和策略只显示摘要，缺少可复核详情 | 提供复用详情模态框、来源说明和安全 Markdown 研究文档 |

## 3. 0.1.0-rc.7 功能范围

### P0

- 研究工作台与 6 个一级业务入口完整可达，影子验证作为策略研究子流程可达。
- 投研助理、统一上下文工具和空白新会话。
- 统一投研报告列表、状态和详情。
- 持仓、自选、风险画像和跨模块对象流转。
- 策略生命周期、影子账本和受确认的自进化。
- 工作区弱感知、独立输入状态、明暗主题和可访问性。
- 后端托管、失败恢复、审计和发布回归。

### P1

- 报告搜索、组合筛选、未读状态和来源追踪增强。
- 产业链关系证据与推断标记的完整展示。
- 产品漏斗和可靠性指标面板。
- 桌面窗口与 1024px 宽度下的布局优化。

## 4. 0.1.0-rc.7 范围外

- 移动端专用产品与小程序。
- 多人共享、团队权限、评论和审批流。
- 券商账户同步、真实委托和自动交易。
- 用户上传或执行任意策略代码。
- 报告协同编辑、公开分享和复杂模板市场。
- 自动购买数据源或绕过数据许可限制。
- 通用工作区的创建、删除和高级权限管理。

## 5. 发布判定

只有同时满足以下条件才可标记 0.1.0-rc.7：

1. 所有 P0 需求有通过评审的设计映射。
2. [产品验收标准](../04-验收发布/02-产品验收标准.md)全部通过。
3. [回归测试矩阵](../04-验收发布/03-回归测试矩阵.md)无 P0/P1 未解释失败。
4. 三套后端不可用、数据为空、任务失败和前台超时均有可恢复体验。
5. 不存在真实交易能力、未确认高影响写入或虚构业务数据。
