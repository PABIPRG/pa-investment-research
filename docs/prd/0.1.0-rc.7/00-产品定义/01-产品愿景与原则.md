# 产品愿景与原则

## 1. 产品定位

投研产品 0.1.0-rc.7 是面向个人投资者与研究人员的证据驱动型研究工作台。它把行情发现、个股分析、策略形成、影子验证、受控进化和个人组合管理连接成一个可追溯闭环。

产品提供研究与风险决策支持，不提供真实证券交易执行，也不承诺收益。

## 2. 核心价值

| 用户问题 | 0.1.0-rc.7 提供的价值 |
|---|---|
| 信息散落，难以形成连续结论 | 用“研究工作台 + 6 个一级入口、7 项能力”串起完整研究生命周期 |
| 模型回答与真实数据脱节 | 通过受控工具读取后端事实，并暴露数据时间与来源 |
| 分析完成后难以再次找到 | 所有重要异步成果进入统一投研报告中心 |
| 策略想法缺少验证约束 | 先回测、再影子运行、满足门槛后才允许进化 |
| 个性化只停留在聊天描述 | 由持仓、自选、KYC、行为画像和风险预算共同驱动 |

## 3. 产品原则

### P-01 事实与解释分离

行情、持仓、策略状态、影子账本、归因和报告由后端持有；模型负责理解和解释。浏览器不得复制一份可与后端分叉的业务事实。

### P-02 页面优先，助手增强

保存持仓、运行分析、迁移策略、运行影子验证和应用进化等确定性动作必须有结构化页面入口。助手不能成为唯一操作路径。

智能分析必须保持结构化任务工作台形态；投研助理只能以右侧停靠或近全屏浮层增强当前业务页，不能取代智能分析页面。

### P-03 证据连续

每个下游动作必须能追溯到上游对象或报告。跨模块流转传递稳定标识，不要求用户重新输入，不复制整段 JSON。

### P-04 高影响动作显式确认

任何会改变策略生命周期、风险画像或持久业务数据的动作，都必须展示影响、等待用户确认并留下审计记录。

### P-05 空状态诚实

后端无数据、不可用或超时时，页面显示真实状态与下一步，不以演示数据填满界面。

### P-06 主流程低认知负担

工作区、端口、任务编号和内部路由不应成为用户完成研究的前置知识。只有排障或高级设置需要暴露这些概念。

### P-07 可恢复而非一次性

刷新、切页、关闭助手或前台等待超时，不能让已经创建的任务和报告失去归宿。

### P-08 风险优先

产品明确数据时效、模拟性质、模型不确定性和风险预算；禁止用“确定上涨”等表达制造收益承诺。

## 4. 0.1.0-rc.7 成功定义

1. 用户能从任一有效市场线索进入分析，并形成可再次打开的报告。
2. 用户能把有证据的分析转为策略候选，完成回测和影子验证。
3. 自进化只在数据门槛满足后提供预案，并在确认后执行。
4. 持仓、自选和风险画像能实际影响事件排序、策略匹配和助手读取的上下文。
5. 6 个一级业务入口、7 项业务能力、报告中心和助手在无模型密钥时仍能清楚区分“直接数据可用”与“模型能力未配置”。
6. 用户无需在输入框看到 JSON，也无需在主流程选择工作区。

## 5. 明确不做

- 真实下单、券商账户控制和自动调仓。
- 无人确认的策略激活、自进化应用或风险画像修改。
- 社区荐股、跟单、收益排行和收益承诺。
- 用模型生成内容替代缺失的真实行情、持仓、产业关系或回测结果。
