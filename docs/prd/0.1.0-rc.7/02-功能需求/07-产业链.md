# 产业链

> 需求前缀：`CHAIN`

## 1. 产品目标

从真实公司或产业节点出发，查看供应商、原材料/设备、研究标的、主营产品和下游客户，支持有界多层探索并保留关系证据。

## 2. 页面范围

- 按公司名称、代码或行业检索。
- 公司档案和产业节点档案。
- 单公司五列产业链。
- 上下游深度与每层数量受控的多层展开。
- 带服务端过滤的网络切片。
- 进入智能分析或投研助理。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| CHAIN-001 | 搜索草稿只属于产业链，不影响全局证券搜索 | P0 |
| CHAIN-002 | 搜索结果能唯一标识公司，并显示代码或区分信息 | P0 |
| CHAIN-003 | 选择公司后固定当前研究标的并读取公司档案 | P0 |
| CHAIN-004 | 五列链路分别显示关系、证据可用性和空状态 | P0 |
| CHAIN-005 | 节点选择后展示节点档案，不改变研究标的身份 | P0 |
| CHAIN-006 | 多层展开只接受受控深度与 TOP 数选项 | P0 |
| CHAIN-007 | 网络切片使用服务端过滤，避免浏览器加载无界全图 | P0 |
| CHAIN-008 | 直接关系、推断关系和未知关系有不同标识 | P0 |
| CHAIN-009 | 关系显示来源或证据说明及数据更新时间 | P1 |
| CHAIN-010 | 可把公司或节点送入智能分析，并保留关系标识 | P0 |

## 4. 关系诚实性

- “暂无可验证关系”不能改写成“无任何关系”。
- 模型补充的推断不得混入后端直接关系，必须单独标注。
- 证据缺失、数据过期和实体歧义必须对用户可见。
- 公司名称相同或证券多地上市时必须要求明确选择。

## 5. 状态保留

- 切换五列、多层、网络视图时保留当前公司。
- 从分析返回时恢复公司、视图、深度和选中节点。
- 快速连续搜索时旧结果不得覆盖新关键词。
- 后端失败时保留已选公司和上次成功关系及其时间。

## 6. 验收

- 空搜索、无结果、同名公司、部分关系为空和后端失败均有明确体验。
- 选择节点不会误把节点名称写进其他模块股票输入。
- 超大网络请求受到前端选项和服务端上限共同限制。
- 进入分析后能追溯到原公司或关系。

## 7. 范围外

- 用户自由上传并合并未经审核的全量图谱。
- 把模型推断自动写成已验证产业关系。
