# 策略研究

> 需求前缀：`STRAT`

## 1. 产品目标

把市场事件和分析证据转为结构化投资假设，在同一页面完成样本外回测、验证分类、影子运行和进入自进化前的证据复核。

## 2. 核心流程

```text
市场事件/分析报告 → 假设预览 → 候选策略 → 样本外回测
→ 画像与预算检查 → 激活或拒绝 → 同页影子验证
```

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| STRAT-001 | 可从事件或报告生成只读假设预览 | P0 |
| STRAT-002 | 用户确认后才把预览加入候选策略池 | P0 |
| STRAT-003 | 策略至少包含名称、标的范围、逻辑、触发、退出、风险和证据引用 | P0 |
| STRAT-004 | 候选策略可运行受控样本外回测并生成报告 | P0 |
| STRAT-005 | 策略池支持全部、候选、活跃、观察、拒绝、退役筛选 | P0 |
| STRAT-006 | 每次状态迁移显示影响并要求显式确认 | P0 |
| STRAT-007 | 状态迁移记录来源报告、原因、时间和操作者 | P0 |
| STRAT-008 | 激活前展示风险画像与预算匹配结果 | P0 |
| STRAT-009 | 激活后可一键进入影子验证并保持当前策略 | P0 |
| STRAT-010 | 模型建议不能直接改变策略状态 | P0 |
| STRAT-011 | 页面提供“策略池”和“影子验证”内部视图，影子验证不再占用一级导航 | P0 |
| STRAT-012 | 策略池提供已验证通过、未验证、验证未通过、已归档四类互斥筛选 | P0 |

| STRAT-015 | 从策略池切换到影子验证及进入自进化时保持同一策略标识 | P0 |

## 4. 页面结构

- “策略池”视图负责四类验证筛选、策略列表、策略详情、样本外回测和受控生命周期动作。
- “影子验证”视图负责同一策略的纸面运行、模拟持仓、净值证据、最近运行和进化就绪状态。
- 旧影子验证深链兼容进入本页的“影子验证”视图，不在侧栏恢复独立入口。
- 四个验证分类的数量之和等于当前全部策略，每个策略只属于一类。

## 5. 策略证据

- 假设必须引用至少一个真实事件、分析报告或用户明确输入。
- 回测显示数据区间、样本内外边界、成本假设、收益、回撤和有效样本。
- 数据不足或回测失败时不可伪造评分，也不可默认激活。
- 策略更新产生版本或审计记录，不覆盖历史证据链。
- “样本不足/成交不足/验证运行中”属于未验证，不得显示为验证未通过。
- 策略详情按实际后端字段展示，缺失项显示数据不足，不由前端补造策略事实。

## 6. 状态与空态

- 无策略时引导从事件、报告或假设预览开始。
- 当前筛选无结果时保留筛选控件，不退回总列表。
- 状态冲突时刷新最新对象并要求用户重新确认。
- 后端失败时保留未提交表单和证据引用。

## 7. 验收

- 假设预览不会创建策略，确认后才出现候选记录。
- 回测成功与失败均产生可追溯状态；成功结果进入报告中心。
- 策略激活后切换到影子验证视图时默认选中同一策略。
- 非法状态迁移在写入前被拒绝，并有用户可理解提示。
- 四类验证筛选互斥且计数完整，生命周期状态同时可见。
- 每类策略均可打开详情，来源、数据时间、验证摘要和失败原因可复核。

## 8. 范围外

- 自定义任意代码策略执行。
- 未经回测与确认的自动激活。
