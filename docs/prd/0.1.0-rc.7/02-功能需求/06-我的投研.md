# 我的投研

> 需求前缀：`MY`

## 1. 产品目标

维护真正影响个性化研究的个人事实：持仓、自选、KYC 风险画像、行为增强画像和组合风险。

## 2. 页面范围

- 持仓查看、添加、编辑、导入与保存。
- 自选添加和移除。
- KYC 问卷、推断、复核和受控调整。
- 行为增强画像说明。
- 集中度、回撤、波动和预算突破。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|

## 4. 数据与隐私

- 持仓、风险画像和报告正文不进入产品分析埋点。
- 浏览器只保留未提交编辑草稿；后端是保存后事实来源。
- 模型读取组合时通过统一工具获得有界数据，不在输入框展开完整持仓 JSON。
- 设置中的会话存储位置变化不应静默改变投研后端中的持仓事实。

## 5. 空状态与失败

- 无持仓：解释添加持仓后可获得的能力，不显示伪资产。
- 无自选：提供添加入口，并说明会影响盯盘与个性化。
- KYC 未完成：当前画像若有默认值，必须标明来源为默认而非问卷结论。
- 风险计算失败：保留持仓并单独重试，不把风险值显示为 `0`。

## 6. 验收

- 保存失败后表单内容仍在，重新提交不会重复记录。
- 持仓更新后工作台、持仓分析和风险预算读取同一版本。
- 自选更新后实时盯盘和个性化事件可见一致结果。
- KYC 调整、重做和取消均有清楚的状态结果。
- 同一风险从工作台和本页打开时，风险标识、原因、阈值、来源和建议一致。
- 事件 Markdown 只整理后端事实字段，危险 HTML 和链接不可执行。

## 7. 范围外

- 券商账户自动同步。
- 多账户税务、资金流水和真实可用资金管理。
