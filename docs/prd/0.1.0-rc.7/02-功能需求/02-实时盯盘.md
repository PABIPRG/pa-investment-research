# 实时盯盘

> 需求前缀：`WATCH`

## 1. 产品目标

帮助用户发现值得研究的市场异动，理解技术信号与快讯，并把线索送入分析或自选，而不是提供交易盘口或下单终端。

## 2. 页面范围

- 自选实时行情与自选管理入口。
- 条件预警列表与创建入口。
- 涨幅榜、量比异动、涨跌停、换手异动、成交额榜。
- 证券详情、技术信号和实时资讯。
- 进入个股分析或投研助理的动作。

## 3. 功能需求

| ID | 要求 | 级别 |
|---|---|---|
| WATCH-001 | 五类扫描独立展示加载、失败和数据时间 | P0 |
| WATCH-002 | 当前选中证券只属于盯盘页面，不覆盖其他模块输入 | P0 |

## 4. 实时性规则

- “实时”指当前数据源可提供的最新数据，不等于交易所零延迟行情。
- 页面必须展示更新时间；超过数据源阈值后标为“可能已过期”。
- 非交易时段明确标注休市、盘前或盘后，不用旧涨跌制造正在交易的错觉。
- 某项数据不足时显示“数据不足”，不把 `0` 当作真实支撑位或压力位。

## 5. 关键流转

- 榜单 → 证券详情：保留原榜单和筛选。
- 证券详情 → 智能分析：传证券与触发信号标识。
- 新闻 → 助理解读：传新闻标识，模型通过工具读取正文或摘要。
- 加入自选 → 我的投研：显示已同步，不要求重复添加。

## 6. 验收

- 至少验证交易中、休市、网络失败、部分数据不足四类场景。
- 快速切换证券时，最终详情必须与当前选中项一致。
- 无自选、无预警时页面仍有明确下一步。
- 页面不出现买入、卖出或真实委托入口。
