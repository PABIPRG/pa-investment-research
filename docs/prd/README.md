# 产品需求文档索引

本目录是产品需求的唯一正式入口。当前生效版本为 [投研产品 1.0 PRD](v1.0/README.md)。

产品研发必须遵循：

```text
PRD 评审通过 → 设计文档评审通过 → 实现计划 → 编码与测试 → 产品验收
```

任何实现中的新想法都必须先回写 PRD 并完成变更评审，不允许以代码现状反向替代产品决策。

## 文档规则

- PRD 只回答“为谁解决什么问题、提供什么行为、如何验收”。
- 技术选型、组件拆分、接口字段和迁移方案进入设计文档。
- 实现步骤、负责人、提交拆分和测试执行顺序进入实现计划。
- 每项需求使用稳定编号，设计、实现和测试必须引用该编号。
- 新版本新建目录；已发布版本只允许勘误，不直接改写产品范围。
