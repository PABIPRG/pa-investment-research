# 云端渠道配置、全局搜索与主题样式修复计划

## 目标与边界

已登录的云端 Web 管理员可在通知中心配置当前实例的 Server 酱、企业微信和邮件渠道，保存后由受管 Python 后台生效；未登录、缺少 CSRF、非可信来源或非受管后台继续拒绝。全局证券搜索聚焦时只显示一层清晰焦点，鼠标、触控和键盘选择结果均进入对应个股详情。本次不修改通用凭据管理接口，也不发送真实通知或部署线上环境。

## 能力映射

| 用户动作 | 现有入口与状态所有者 | 缺口 | 决定 |
| --- | --- | --- | --- |
| 检索并打开证券 | `GlobalStockSearch`、`market-watch.security-search`、`InvestmentUiState.navigate` | 浏览器点选时菜单可能在点击前因失焦关闭；焦点边框与描边叠加 | 扩展现有控件 |
| 配置外部渠道 | `NotificationChannelSettings`、`NotificationSettings` 凭据文件、Python 投递队列 | 连接层仅允许回环；运行时拒绝 `cloud-web` | 扩展专用接口权限 |
| 鉴权与持久化 | WebAuth 管理员会话、CSRF、可信 HTTPS 代理；实例凭据服务 | 云端专用接口尚未接入管理员许可 | 组合既有能力 |

渠道状态、权限、配置版本和投递结果均为确定性事实，不使用模型推断。凭据只写实例所属凭据存储，不通过通用 `request-data`，也不在响应或日志中回显。

## 实施顺序

1. 先补连接层与运行时回归：管理员会话加 CSRF 可访问专用接口；匿名、缺少 CSRF、非可信来源与未启用鉴权的远端请求拒绝；云端受管后台可读取配置，附着后台继续拒绝。
2. 修复搜索点选前失焦与焦点视觉；补行为测试，检查键盘选择与真实浏览器点击。修正文案中的“本机”为“当前实例”，保留加载、错误、只读、保存、测试与移除状态。
3. 运行聚焦测试、类型与构建检查；在真实产品入口验证搜索、通知设置与云端权限拒绝。真实外部投递使用假适配器验证，不使用用户凭据。

## 验收与恢复

验收覆盖 1440px、1024px、窄屏可达性、浅色和深色、首次加载、空配置、保存失败、重试与无权限。云端配置变更只影响专用接口；若上线后发生权限或同步故障，可回退此特性分支并恢复原回环限制，既有凭据文件无需迁移。未执行的真实服务接收或线上部署明确记为未验证。
