# PAB-19 Web 文件能力与部署能力设计

## 目标与边界

为本机 Web、Electron 和云端 Web 建立由 Host 声明的部署能力模型，并让投研备份、目录操作与券商持仓同步按该模型工作。云端 Web 只暴露浏览器上传、下载和手工持仓，不暴露服务器绝对路径、目录选择、打开本机文件夹或券商客户端扫描。

本次不包含容器入口、健康检查、镜像发布、版本号或应用图标；这些分别属于 PAB-20、PAB-21、PAB-22。

## 能力模型

新增不可变 `deploymentCapabilities` Host 服务，部署面为 `cli`、`local-web`、`electron` 或 `cloud-web`。服务把部署面映射为客户端安全的布尔能力和持仓数据源白名单：

- `local-web`：浏览器文件传输、服务器目录管理与原生打开路径可用；券商同步可用，但没有 Electron 原生自动化。
- `electron`：浏览器文件传输、目录管理、原生打开路径、券商同步和原生自动化均可用。
- `cloud-web`：仅浏览器文件传输和手工持仓可用；服务器目录、原生路径与券商同步全部拒绝。
- `cli`：不声明浏览器入口；保留 Host 本身的本地运行能力。

Web 启动通过显式 `DSH_DEPLOYMENT_SURFACE=local-web|cloud-web` 选择部署面，缺省为 `local-web`。不能根据绑定地址、认证模式、浏览器平台或 User-Agent 推断云端。

## 文件传输

沿用受 PAB-17 全链路鉴权与 CSRF 保护的 Typert Remote：导入继续使用有上限、可取消的分块上传；新增有上限、可取消的分块下载。下载会话只接受备份列表返回的直接子文件名，拒绝符号链接、非普通文件、超限文件和无效归档。

云端的备份描述返回“托管存储”而不是目录字符串；设置页因此不渲染路径、复制、打开文件夹或更改位置。已存备份提供浏览器下载按钮。导入预览关闭时显式释放，上传可以在进行中取消，过期预览回到重新选择入口。

## 持仓与 Host 限制

`cloud-web` 在后端拒绝持仓来源探测、自动检测、券商同步以及切换到非手工数据源；`holdings`、`holdings-save`、单条录入和批量导入保持可用。Electron 原生持仓入口也由同一 Host 能力检查。

ApiProxy 在云端不返回 `cwd`，`canOpenPath=false`，目录选择、目录列举、目录创建和打开路径均返回不可用。目录选择自动装配器在云端不挂载任何目录后端或客户端面。

## 兼容与验证

能力字段以向后兼容的 Host 描述扩展发布；`cwd` 改为可选，现有会话创建仍由 Host 自己使用内部默认目录。验证覆盖能力矩阵、显式启动配置、Host 拒绝、备份上传/下载/取消/过期、云端持仓拒绝、本地回归，以及浅色/深色和 1440/1024/窄屏真实 Web 验收。
