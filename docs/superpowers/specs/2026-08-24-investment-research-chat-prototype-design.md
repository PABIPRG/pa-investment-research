# 投研对话交互稿设计

## 目标

交付一个可直接在浏览器打开的单文件 HTML 交互稿，供产品审查投研对话的新版布局与会话管理流程。交互稿只覆盖对话模块，不修改现有 React、Cordis profile 或后端实现。

## 页面结构

页面由顶栏、主对话区和右侧历史面板组成，不设置左侧导航。

- 顶栏左侧展示“投研智能体”和当前会话标题，右侧固定展示蓝色主按钮“新对话”。历史面板收起后，该按钮仍然可见。
- 主对话区使用居中的单列阅读布局。消息正文最大宽度为 `748px`，输入框最大宽度为 `780px`，底部输入区固定在可视区域下方。
- 历史面板展开宽度为 `288px`，收起后显示为 `48px` 窄轨。窄轨保留历史图标和展开按钮，不显示会话内容。
- 桌面端对话区随历史面板展开或收起平滑调整宽度。移动端不显示窄轨，历史记录从右侧抽屉进入。

## 视觉规则

交互稿沿用 Technical Precision 设计系统：浅灰工作台、白色主内容面、`#1155c4` 主色、低对比度描边、4px 间距网格、Inter 与 JetBrains Mono 字体栈。

“新对话”是页面唯一的主操作，使用实心蓝色按钮。历史面板、会话操作和输入附件等次级操作使用描边或无底色按钮。用户消息使用浅蓝气泡，助手消息直接呈现在白色内容面上。结构化投研结果使用紧凑表格与状态标签，不引入独立业务页面跳转。

## 会话管理

历史面板顶部提供会话搜索，列表按“今天”“最近 7 天”“更早”分组，并按最近更新时间倒序排列。

每个会话支持切换、重命名和删除。当前会话显示蓝色选中状态。删除当前会话后，页面选择最近更新的剩余会话；没有剩余会话时创建一个空白会话。

点击“新对话”立即创建并进入空白会话。空白会话显示欢迎语和投研快捷问题。用户发送第一条消息后，标题由首条问题自动截取生成；用户重命名后的标题不再被自动标题覆盖。

切换会话时恢复该会话的消息、输入草稿和滚动内容。搜索匹配会话标题与消息文本；无匹配结果时显示空状态，不改变当前会话。

## 对话交互

输入框支持自动增高，`Enter` 发送，`Shift+Enter` 换行。快捷问题点击后作为用户消息发送。实时联网开关只改变交互稿中的展示状态，不访问网络。

发送消息后先追加用户消息，再短暂显示助手生成状态，最后返回确定性的模拟投研回答。示例回答覆盖普通文本、风险标签、AI 信心指数、持仓指标表格和后续问题建议，用于审查内容密度与长消息滚动体验。

“新对话”不弹出确认。删除会话需要轻量确认；重命名使用会话行内输入。附件按钮、联网开关和非真实业务动作通过提示消息反馈，不上传文件或调用服务。

## 前端状态

交互稿使用 `localStorage` 键 `pa-investment-research.chat-prototype.v1` 保存以下状态：

```ts
interface PrototypeState {
  activeConversationId: string
  historyCollapsed: boolean
  conversations: Array<{
    id: string
    title: string
    titleSource: 'automatic' | 'manual'
    createdAt: string
    updatedAt: string
    draft: string
    messages: Array<{
      id: string
      role: 'user' | 'assistant'
      content: string
      createdAt: string
      kind?: 'text' | 'portfolio-comparison'
    }>
  }>
}
```

首次打开时写入三组演示会话并选择最近更新的一组。存储内容损坏时恢复演示数据；浏览器拒绝写入或容量不足时继续使用当前内存状态，并显示“本次更改仅在当前页面有效”。

## 响应式行为

- 视口宽度大于 `900px`：历史面板显示为 `288px` 展开面板或 `48px` 窄轨。
- 视口宽度不大于 `900px`：历史面板默认关闭，通过顶栏历史按钮打开右侧抽屉；抽屉宽度不超过视口的 `88%`。
- 视口宽度不大于 `640px`：顶栏隐藏当前会话副标题，消息区与输入区左右留白缩减为 `16px`，结构化表格支持横向滚动。

## 验收标准

- 单文件 HTML 无构建步骤，可直接打开并完成新建、切换、搜索、重命名、删除和收起历史面板。
- 刷新页面后恢复会话、草稿、当前选择和历史面板状态。
- “新对话”在桌面与移动布局中始终作为可见的主操作。
- 对话模块外不出现机会发现、持仓分析、投研框架、项目组合、投研任务或知识库导航。
- 桌面端、窄桌面端和移动端均无页面级横向溢出；只有结构化表格允许局部横向滚动。
- 交互稿不发起网络请求，不读取仓库业务数据，也不改变现有 profile 行为。
