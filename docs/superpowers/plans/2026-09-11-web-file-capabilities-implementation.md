# PAB-19 Web 文件能力实施计划

1. 新增部署能力 Host 服务和能力矩阵测试，在基础组合、本机 Web、云端 Web 与 Electron 组合中由运行时显式选择部署面。
2. 扩展 ApiProxy 的 Host 描述和目录/打开路径门禁，云端不挂载目录选择器，也不返回 Host 工作目录。
3. 在投研 Runtime 接入同一能力服务：限制云端券商操作和备份目录管理，新增校验、分块、取消均有上限的备份下载协议，并补充预览取消。
4. 更新投资 Runtime 客户端与设置页：托管存储文案替代绝对路径、备份下载、上传取消、预览取消和过期恢复；持仓设置与工作台按 Host 白名单隐藏券商入口。
5. 更新中英文文档、能力支持矩阵和 Agent Note；运行聚焦测试、类型检查、GUI 样式检查、Web 构建与 3094 隔离真实浏览器验收。
6. 自审后创建 `[AI]` 提交，推送 `private/codex/pab19`，创建到 `public/master` 的 `[AI]` 跨仓 PR，并把测试、UAT 与风险写回 PAB-19 后设为 In Review。
