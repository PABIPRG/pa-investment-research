# 投研智能体单镜像容器部署实施计划

1. 为 Python sidecar 增加带归档和 requirements SHA-256 的 `linux-x64` 目标，并用构建器测试固定平台描述符。
2. 增加 CLI 生产依赖闭包组装脚本，复用现有 pnpm workspace 链接物化和无符号链接复制机制。
3. 增加容器入口、聚合健康检查、Dockerfile、Compose、示例环境文件和严格构建上下文排除规则。
4. 增加契约测试与维护者文档，记录认证、卷、时区、单实例、关停、升级和回滚操作。
5. 增加不推送镜像的 PR 工作流，生成按 commit SHA 标记且可复用的 OCI 交付归档与元数据。
6. 运行聚焦测试、类型检查、构建和文档校验；本机无 Docker 时由 PR CI 完成镜像与 Compose 运行验证，并把真实反向代理浏览器验收保留给 PAB-21。
