## 数据来源与口径

- `/live` 一次有界读取 `holdings.default`。今日通过既有 market-watch `/quotes/batch` 获取同一批报价并计算汇总与逐只明细；单只缺报价时证券、数量与成本仍展示，整组市值、浮盈和收益率为缺失。现金、初始资金与完整总权益不借持仓金额推断。
- 历史日期只沿用截至该日已记录的最近持仓快照，并返回 `holdings_as_of`；无此前记录时不可用，不以今日持仓回填。历史报价按所选日期读取，缺失时不补为今日价。
- `/history` 复用 `portfolio_performance` 的持仓变更资金流估算和历史行情缓存。公开 GET 使用一次有界文档视图，不调用私有 `/portfolio/performance` 中的 `ensure_legacy_seed`。曲线及月历均注明估算、不含现金、历史起点与缺失行情；调仓市值差额不直接计为盈亏。
- 操作时间线沿用已有归档分页索引、起点、游标与详情。持仓资料调整和成交资料记录使用原有区分，记录时间不冒充实际成交时间。研究活动从有界报告库读取，仅输出固定类型名称、时间、完成状态与固定摘要；研究公开起点由 `DSH_PUBLIC_OBSERVATORY_RESEARCH_SINCE` 单独控制，原始标题、任务参数、正文、账户标识和链接不输出。

## 公开限制与状态

Host 保留公开开关、精确来源/Host、方法与参数白名单、限流、并发、超时及响应大小限制。新增路由仅映射固定内部只读路径；Python 新响应使用严格 Pydantic 字段模型。业务端口仍需保持内网隔离，CORS 不承担鉴权。报告或操作起点撤销后新请求不再返回对应活动；旧游标失效须清除旧页。前端各区块独立加载，刷新失败只保留同一查询的旧结果并标记可能过期；切换日期取消旧请求。
