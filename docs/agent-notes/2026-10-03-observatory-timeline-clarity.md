## 体验与实现决策

用户主任务是快速查看持仓历史、从任意位置播放，以及辨认日历缺失状态。支持 1440 / 1024 / 768 / 390px 与明暗主题。收益计算说明使用已有 `HelpPopover` 的可选悬停模式；点击可固定、键盘聚焦可打开、Escape 或外部点击关闭，不新增弹窗体系。历史区间置于标题右侧，日历说明合并为相邻入口；真实部分缺失和刷新失败继续保留可见提示。

时间线使用截至当日最近 90 日的完整历史，详情仍按所选日期读取。复用 `loadObservatorySlice` 的取消、请求代次与独立刷新机制，跨查询只保留相同范围的历史；其他模块仍清空旧日期内容。序列和索引由历史及日期派生，点击“第一天”定位窗口内首个有效估值，选择历史日不会缩短区间。播放时只移动游标，暂停、结束和静止时拖动才切换详情；只保留“播放 / 暂停”，去掉“查看此日”额外操作。刷新后的点集变化按日期定位，不保存容易漂移的数字索引。当前取舍是切日仍重新查询同一历史范围，未为本轮新增第二套加载状态。

交易日缺估值或缺收益基准使用现有警示浅底、虚线边框及“缺估值 / 缺基准”文字，休市使用中性色和“休市”；未来交易日显示“未到”，不渲染为历史数据缺失。未知交易日保持“待确认”，不推断为交易日。缺失金额仍为“—”。设计口径已同步到 [DESIGN.md](../../DESIGN.md) 与[应用说明](../../frontend/apps/public-observatory/README.md)。

| 状态 | 适用性与处理 |
|---|---|
| 初次加载、后台刷新 | 适用；沿用独立加载图标，已有完整时间线在切日与刷新时保留 |
| 空数据、单点 | 适用；空态解释、首日/播放按有效点禁用，不补零 |
| 部分成功、过期、错误 | 适用；缺失可见，刷新失败保留完整历史并允许重试 |
| 筛选无结果 | 既有活动筛选未变，沿用原空态与竞态保护 |
| 无权限 | 本轮没有权限变化，沿用公开 API 错误入口；生产权限未验证 |
| 成功、禁用 | 游标、日期、进度和详情反馈一致；仅一个有效点时说明无法自动推进 |
| 确认、撤销、持久化 | 不适用；本轮操作均为本地只读浏览状态 |
