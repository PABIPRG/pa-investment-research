# 公开观察室浏览器反馈修订

关联 PAB-30 及 2026-09-29 六条浏览器反馈。工作分支为 `codex/public-observatory-feedback`，初始基准 `d918f686`。本次未访问用户远程服务器，也未部署。提交与 PR 状态以 Git 记录为准。

## 能力核查与决策

| 用户动作 | 现有入口与数据所有者 | 缺口 | 决策 |
| --- | --- | --- | --- |
| 播放历史 | 观察室 `App`、`/history`、ECharts；共享 `ProgressBar` | 逐帧切换全局日期引发多区块重读，缺少进度控制 | 组合现有历史点与进度条，在暂停或结束时切换全页日期 |
| 看持仓指标 | `/live` 的持仓与行情汇总 | 现金和完整权益没有可信来源，两个空指标占据首屏 | 复用持仓金额，合并缺失说明，不推断账户权益 |
| 识别操作证券 | 持仓操作索引的已校验 `holdings_changes` | 列表标题不含证券，旧索引存储通用标题 | 扩展公开投影，在有界列表读取中从已校验详情补充代码 |
| 展开与查看日历 | 共享全屏图标、主题语义 token、日历状态 | 文字按钮及盈亏和休市格缺少区分 | 复用图标和现有语义色，保留数字符号及状态文字 |

证券代码、金额、日期和交易状态均由确定性数据产生，不使用模型推断。对于历史持仓资料不完整、无法核对变更证券的记录，仍显示通用标题；不补造证券名称。操作摘要保留在详情中，列表只保留时间与有区分度的标题。

## 验证与限制

聚焦后端测试 43 项通过，覆盖旧索引操作标题、单只及多只证券、脱敏与既有公开接口；前端测试 11 项通过，覆盖播放预览不逐帧请求、加载竞态和 API 独立失败。类型检查、主题样式检查和生产构建均通过。浏览器本地文件访问被 Browser Use 安全策略拒绝，未对真实渲染、视口和深浅主题作通过声明。没有访问生产页面或服务器，也没有确认交互稿的原始图标与色值；视觉逐项对照仍需在允许的本地验收环境完成。
