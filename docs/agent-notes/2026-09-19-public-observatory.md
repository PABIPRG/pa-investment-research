# Agent Note：免登录公开观察室与只读账户投影

Status: implemented

关联 [PAB-30](https://linear.app/pabiprg/issue/PAB-30/建立免登录公开观察室与只读投研投影)。生产目标域名为 `pair-observe.xiexin.dev`；本次没有创建 Vercel Project、写入生产环境变量、绑定域名或部署。

## 问题

离线交互稿定义了一个免登录、只读的账户表现入口，但仓库原有能力只有受保护的 Web API、持仓与成交事实，以及不包含现金的持仓历史表现。直接公开既有接口会放宽认证边界；直接复用持仓表现会把不完整数据误述为全账户权益；把页面放进官网目录又会把两个独立 Vercel Project 的构建与域名生命周期耦合。

## 决策

- 在 `frontend/apps/public-observatory` 新建独立 Vite/React 应用，复用主题、Button、Select、HelpPopover、Modal 与应用图标；DatePicker、MonthPicker 下沉到共享 UI primitives。页面不包含演示数据，构建时只接受 `VITE_PUBLIC_API_BASE_URL`。
- 在 trading-core 的账户所有者内增加不可变账户快照和公开 DTO。金额使用定点十进制字符串，`snapshot_id` 与 `data_revision` 贯穿概览、持仓、权益曲线、日历和活动；指定日期缺失时不回退、不插值，公开读取不触发迁移、同步或写入。
- 新建 Host 公开读取包，只接收固定前缀下的 GET、HEAD 与精确 OPTIONS。Origin、Host、查询参数、响应体大小和速率独立校验；后端路径由代码固定，浏览器不能选择内部地址。原有受保护接口判断保持不变。
- 页面按交互稿提供逐日切换、日期与月份选择、留存快照播放、权益轨迹键盘点选、持仓明细、活动筛选与展开详情。历史日期暂停自动刷新；失败刷新保留上次成功快照并给出可恢复提示。
- 生产 Origin 只通过 `DSH_PUBLIC_OBSERVATORY_ORIGIN` 显式注入；未配置时公开 Host 插件不启用。根 Compose 显式映射 Origin、操作起点、快照批准 ID 和私有写令牌，示例默认关闭；已有服务器 Compose 需单独合并映射并重新创建容器，镜像升级不代表配置升级。Vercel 预览域名不会自动获得生产数据权限。
- 筛选与重试使用现有 App 状态，不新建状态所有者；两个共享 Select 保留可见标签并支持一次清除，重试期间按钮禁用并显示反馈。计算口径使用锚定 HelpPopover，通用动作使用 Button；日历格和活动整行保留业务交互，不用全局 button 样式强行覆盖组件。

## 与交互稿的有意差异

- 原稿顶部的“查看状态”和“市场状态”是离线演示开关，正式页面不保留。
- 原稿使用浏览器原生 date/month 输入；正式页面改为共享自定义选择器，以满足跨浏览器主题、键盘和焦点契约。
- 原稿能切换模拟交易中/休市；当前公开 DTO 没有权威市场状态，正式页面只标识“A 股 · 公开快照”，不推断休市日。
- 正式页面增加 snapshot/revision、新鲜度、部分成功和失败保留提示；这些是原稿未能表达的真实数据边界。

## 2026-09-23 部署配置与组件回归（PAB-30，尚未发布）

生产只读检查确认 Vercel 已使用正确 API 地址，但正式 Origin 的公开概览与操作请求均返回 404，未返回允许该 Origin 的跨域标头；当前 Docker 镜像包含公开模块，部署 Compose、环境文件及运行容器均缺少四项观察室配置。镜像更新不等于启用公开入口。本轮只修复仓库配置传递与前端组件，不修改生产配置、不扩大公开范围、不重启容器、不部署。

私有 Web 的持仓成本、市值和浮盈来自 `holdings.default` 与行情，市值不含现金；`account_snapshots` 的 0 表示完整账户快照记录数，不表示账户金额为零。已有持仓与行情可以复用，现金、初始资金与完整账户历史的接入不在本轮范围内。页面现在区分“请求失败，无法确认快照状态”和“尚无可公开的完整账户快照”，不再把网络失败断言为数据缺失。

体验契约：访客仍在同一观察室查看所选日期，App 保持唯一筛选与加载状态所有者；类型、状态使用共享 Select，清除按钮一次重置两项，空结果与请求失败分开呈现。重试显示等待反馈并阻止重复操作，操作加载不依赖账户快照。计算口径使用 HelpPopover，通用动作使用共享 Button 与小圆角；保留只读语义，确认和撤销不适用。未改变资金计算、账户生产器、批准规则与刷新保留旧数据的契约。
