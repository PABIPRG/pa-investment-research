# 券商持仓接入方案

> 代码入口：`adapter/holdings_providers/`；产品用户通过设置页或持仓弹窗选择数据源，源码调试也可使用 `HOLDINGS_PROVIDER` 环境变量

## 方案对比

| | **manual** | **easytrader** | **mac_ths** | **qmt** | **joinquant** |
|---|---|---|---|---|---|
| **数据来源** | 用户手动录入 | 通达信/同花顺客户端（GUI 自动化） | 同花顺 Mac 版（AppleScript 自动化） | miniQMT/xtquant（官方 Python API） | 聚宽 jqdatasdk |
| **真实持仓** | ✅（手动维护） | ✅（实时读取） | ✅（实时读取） | ✅（实时读取） | ❌（仅行情/财务数据） |
| **模拟持仓** | 手动维护 | ✅（匹配模拟炒股窗口） | ✅（自动切换模拟 tab） | ✅（独立模拟账号） | ❌ |
| **券商权限** | 无需 | 无需（只需安装客户端） | 无需（只需安装客户端） | 需开通 QMT（通常 10 万门槛） | 需购买授权（~¥6999/年） |
| **稳定性** | ⭐⭐⭐⭐⭐ | ⭐⭐（UI 自动化，受客户端版本影响） | ⭐⭐（UI 自动化，受客户端版本影响） | ⭐⭐⭐⭐⭐（官方 API） | ⭐⭐⭐⭐（数据 API 稳定） |
| **速度** | 即时 | 秒级（需操作 GUI） | 秒级（需操作 GUI） | 毫秒级（IPC 直连） | 秒级（网络请求） |
| **覆盖券商** | 任意 | 通达信/同花顺（几乎所有券商） | 同花顺 Mac 版内置的 80+ 券商 | 60+ 家（华鑫、国金、中泰等） | 聚宽平台 |
| **平台** | 跨平台 | 仅 Windows | 仅 macOS | 仅 Windows | 跨平台 |
| **适合场景** | 临时/测试 | 快速验证，无券商门槛 | macOS 用户快速验证，无券商门槛 | 生产环境长期使用 | 行情数据补充 |

## §manual — 手动录入

当前默认方案。用户通过 `POST /holdings/save` 或 dsh 对话维护持仓，落 `JsonStore`（`data/adapter/holdings.json`）。

**配置：** 应用内选择会立即生效并持久化；源码调试也可使用：
```env
HOLDINGS_PROVIDER=manual
```

无需额外配置。

## 真实与模拟账户

产品通过 `HOLDINGS_ACCOUNT_MODE=real|simulated` 明确区分操盘账户，缺省为 `real`。数据源和账户类型都通过持仓同步面板即时切换并持久化；同步结果分别记录为 `broker_real` 与 `broker_simulated` 快照来源，避免把模拟持仓误标为真实持仓。

各平台使用自身稳定能力实现账户选择：macOS 同花顺由 AppleScript 自动切换“A股”或“模拟”tab；Windows easytrader 在已连接进程中匹配真实交易窗口或标题含“模拟炒股”的窗口；QMT 使用单独的模拟账号 ID。系统不会在找不到模拟窗口或模拟账号时回退读取真实账户。

## §easytrader — CLI/GUI 自动化接入

通过 [easytrader](https://github.com/shidenggui/easytrader) + pywinauto 操控券商客户端窗口，读取持仓/资金/委托。

### 覆盖范围：按内核适配，覆盖贴牌券商

国内券商 PC 客户端大多是「贴牌」生态（采购同花顺/通达信内核定制），因此按内核适配一次即可覆盖一大批券商：

| 内核 | easytrader 模式 | 锚定程序 | 覆盖券商 |
|------|----------------|----------|---------|
| 同花顺 | `thstrader` | `xiadan.exe` | 80+ 家（平安/国金/银河/华泰/招商/中信建投…） |
| 通达信 | `tdxtrader` | `tdxw.exe` | 60+ 家（各家通达信定制版） |

全部券商档案见 `adapter/holdings_providers/broker_profiles.py` 注册表
（`THS_BROKERS` / `TDX_BROKERS`，遗漏的券商在表尾追加一行即可）。
CLI 随时可查：

```bash
env\Scripts\python.exe holdings_cli.py detect --list   # 列出全部支持券商
```

### 快速接入（推荐：自动发现）

```bash
# 1. 装依赖
env\Scripts\python.exe -m pip install easytrader pywinauto
# 2. 扫描本机已装券商客户端，自动识别券商并生成 .env 建议
env\Scripts\python.exe holdings_cli.py detect
# 3. 把建议配置粘进 .env，启动并登录券商客户端后自检
env\Scripts\python.exe holdings_cli.py check
```

### 前置条件

1. **Windows 系统**（pywinauto 依赖）
2. **券商客户端**：安装对应内核客户端（同花顺贴牌券商装其「同花顺版」）并登录；
   同花顺通用版内置 80+ 券商账号登录，装一个即可覆盖大多数券商
3. **Python 依赖**：
   ```bash
   pip install easytrader pywinauto
   ```

### 配置（.env，二选一）

```env
HOLDINGS_PROVIDER=easytrader
# 方式 A：按券商档案（推荐，detect 自动生成）
EASYTRADER_BROKER=pingan                 # 档案 id 见 detect --list
EASYTRADER_CLIENT_PATH=C:\平安证券\同花顺版\xiadan.exe
# 方式 B：按内核（不区分具体券商）
EASYTRADER_CLIENT_TYPE=thstrader         # thstrader(同花顺) | tdxtrader(通达信)
EASYTRADER_CLIENT_PATH=C:\同花顺\xiadan.exe
# 模拟交易窗口由不同程序承载时可单独指定；同一程序承载时留空
EASYTRADER_SIM_CLIENT_PATH=
```

`EASYTRADER_BROKER` 优先于 `EASYTRADER_CLIENT_TYPE`；进程检测与报错文案按档案执行。

### 字段映射

字段候选名由 `adapter/holdings_providers/_ths_fields.py` 统一维护，与 §mac_ths 共用：

| easytrader 返回字段 | HoldingItem 字段 | 转换说明 |
|---------------------|-----------------|----------|
| `证券代码` / `股票代码` / `stock_code` | `ticker` | 截取前6位数字 |
| `股票余额` / `持仓数量` / `证券余额` / `volume` | `quantity` | int → float |
| `成本价` / `参考成本价` / `成本均价` / `avg_price` | `cost_price` | 直接映射 |

### 已知问题

- 客户端窗口**必须保持打开且已登录**，最小化或遮挡可能导致操作失败
- 券商客户端版本更新后，UI 控件定位可能失效，需更新 easytrader 配置
- 查询速度受 GUI 操作延迟影响（约 2-5 秒/次）
- 推荐 fork：[shidenggui/easytrader](https://github.com/shidenggui/easytrader)（社区持续维护）
- 模拟操盘会优先匹配标题含“模拟炒股”的交易窗口；如果窗口尚未创建，用户只需首次在 Windows 同花顺中进入“交易 → 模拟 → 持仓”，后续同步会复用该窗口

### 降级

当 easytrader 不可用（客户端未启动/未登录）时，`is_available()` 返回 `False`，`get_holdings()` 抛 `ProviderUnavailable`。上层可 fallback 到 manual。

## §mac_ths — 同花顺 Mac 版 + AppleScript 接入

macOS 上没有 pywinauto，也没有券商自研的下单客户端（`xiadan.exe` 等全是 Windows PE），
因此不能复用 §easytrader。macOS 唯一能登录券商并看到持仓的现成客户端是**同花顺 Mac 版**
（内置 80+ 券商账号登录，含平安、国金、银河、中信、广发等），
本 Provider 用 macOS 自带的 AppleScript + System Events 辅助功能 API 遍历它的 Cocoa 控件树，
等价于 pywinauto 在 Windows 上做的事。

代码入口：`adapter/holdings_providers/mac_ths.py`。

AppleScript 里的「交易 → A股/模拟 → 股票 → 持仓」点击序列与控件路径参考了
[zetatez/evolving](https://github.com/zetatez/evolving)（MIT）沉淀的常量，并做了三处改造：
只取持仓（去掉下单/撤单/银证转账等资金操作入口）、输出改为 TAB/换行分隔的文本
（上游返回 AppleScript list 时 `osascript` 会用逗号拼接，`1,000` 这类千分位会被拆错列）、
表格定位改为在 `scroll area 1..8` 里找表头含「代码」的表并按表头名映射列
（上游写死 `scroll area 4 / 5`）。

### 前置条件

1. **macOS**
2. **同花顺 Mac 版**已安装并登录券商交易账号，窗口停在「交易」模块
3. **自动化授权**：系统设置 → 隐私与安全性 → 自动化，允许运行本应用的进程控制 System Events
4. **辅助功能授权**：系统设置 → 隐私与安全性 → 辅助功能，勾选运行本应用的进程
   （开发期直接跑源码时勾选终端；打包后勾选「投研智能体」）。
   若列表里没有，点「+」手动添加对应 `.app` 或终端程序。
   **授权后需要重启应用才生效。**
5. `osascript`（macOS 自带，无需安装）

> 授权失败时 `osascript` 会以 -1743（不允许发送 Apple 事件）或 -25211（未获辅助功能授权）
> 退出，本 Provider 会把这些英文错误换成上面的中文操作指引，不会把原文丢给用户。
> 打包侧已声明 `com.apple.security.automation.apple-events` entitlement 与
> `NSAppleEventsUsageDescription`（见 `apps/electron/src/packaging.ts`、`entitlements.mac.plist`）。

### 配置（.env）

```env
HOLDINGS_PROVIDER=mac_ths
HOLDINGS_ACCOUNT_MODE=real     # simulated 时自动切换“模拟”tab
MAC_THS_APP_NAME=同花顺      # 可选，留空即默认「同花顺」
MAC_THS_TIMEOUT=60           # 可选，osascript 超时秒数
```

### 字段映射

与 §easytrader 共用 `_ths_fields.py` 的候选列名。macOS 侧多一层「按表头名定位列号」
（`locate_columns`），因此客户端调整列顺序不会取错值；表头里找不到代码列时，
错误信息会把实际表头回显出来，便于补充列名映射。

数值容错：客户端展示的 `1,000`、`¥3,700.00`、`--`、`—` 都会被正确解析或按 0 处理
（数量为 0 的行视为已清仓，不写入持仓）。

### 已知问题与未验证项

- 客户端窗口**必须保持打开且已登录**；同花顺改版会导致控件路径失效，与 §easytrader 同源风险
- 查询速度受 GUI 操作延迟影响（秒级）
- ⚠️ **AppleScript 正文尚未在真机验证**：开发机为 Windows，无法执行或做语法校验。
  已通过单测覆盖的只是「脚本产出 → 持仓」的解析与全部错误分支
  （`tests/test_mac_ths.py`）以及平台门禁。控件路径、点击序列、表头文案
  需在装有同花顺 Mac 版且已登录券商账号的机器上人工验证。
  若报「未在交易窗口找到持仓表格」，请对照实际界面调整 `mac_ths.py::_APPLESCRIPT_TEMPLATE`
  里的点击序列与 `scroll area` 搜索范围。
- 部分券商在同花顺 Mac 版上无交易权限（只能看行情），此时点「交易」会失败并返回 `ERR`，
  本 Provider 会把原因原样透出
- macOS 上不做磁盘递归扫描：`/holdings/source/detect` 只认同花顺 Mac 版这一个客户端，
  未安装时返回空列表 + 安装/授权引导

### 降级

当 `mac_ths` 不可用（未安装/未运行/未授权）时，`is_available()` 返回 `False`，
`get_holdings()` 抛 `ProviderUnavailable`。上层可 fallback 到 manual。

## §QMT — 迅投 miniQMT/xtquant 接入

通过 [xtquant](https://pypi.org/project/xtquant/) 连接 miniQMT 客户端进程，获取真实持仓/资金/委托。**推荐的生产级方案。**

### 前置条件

1. **券商开户** + **开通 QMT 权限**（部分券商需 10 万+ 资产门槛，华鑫证券门槛较低）
2. **miniQMT 客户端**：下载并登录（券商官网或 QMT 官网获取）
3. **Python 依赖**：
   ```bash
   pip install xtquant
   ```

### 配置

```env
HOLDINGS_PROVIDER=qmt
QMT_ACCOUNT_ID=你的资金账号
QMT_SIM_ACCOUNT_ID=你的模拟账号   # 使用 simulated 时必填，不回退到真实账号
QMT_SESSION_ID=888888
```

### 字段映射

| xtquant 字段 | HoldingItem 字段 | 转换说明 |
|-------------|-----------------|----------|
| `stock_code` | `ticker` | `"600519.SH"` → `"600519"`（去后缀取6位数字） |
| `volume` | `quantity` | int → float |
| `avg_price` | `cost_price` | 直接映射 |

### 扩展能力

QMTProvider 额外提供 `get_asset()` 方法查询账户资金：

```python
provider = QMTProvider()
asset = provider.get_asset()
# {"total_asset": 1000000.0, "cash": 500000.0, "market_value": 500000.0, "frozen_cash": 0.0}
```

后续可扩展：
- `query_stock_orders()` — 查询当日委托
- `query_stock_trades()` — 查询当日成交
- 下单/撤单（需合规确认 + 风控层）

### 支持 QMT 的常见券商

| 券商 | 门槛 | 说明 |
|------|------|------|
| **华鑫证券** | 较低 | 推荐，miniQMT 开通门槛低 |
| **国金证券** | 中等 | QMT 支持较好 |
| **中泰证券** | 中等 | 同时支持原生 XTP 接口 |
| **华泰证券** | 较高 | 需 50 万+ |
| **东方财富** | 中等 | EMQuantAPI |

### 降级

当 QMT 不可用（xtquant 未安装 / miniQMT 未运行 / 账号未配置）时，`is_available()` 返回 `False`，`get_holdings()` 抛 `ProviderUnavailable`。

## §joinquant — 聚宽数据源

**聚宽不提供真实券商持仓**，仅提供行情/财务数据。设 `HOLDINGS_PROVIDER=joinquant` 会直接抛 `ProviderUnavailable`。

本 Provider 保留结构供未来扩展（如拉历史行情补充 L1 风险分析），不作为持仓数据源使用。

## 降级链

```
用户请求 → get_provider()
  │
  ├─ HOLDINGS_PROVIDER=qmt
  │    └─ is_available()?  → ✅ get_holdings()
  │                     → ❌ fallback 到 easytrader
  │
  ├─ HOLDINGS_PROVIDER=easytrader   （仅 Windows）
  │    └─ is_available()?  → ✅ get_holdings()
  │                     → ❌ fallback 到 manual
  │
  ├─ HOLDINGS_PROVIDER=mac_ths      （仅 macOS）
  │    └─ is_available()?  → ✅ get_holdings()
  │                     → ❌ fallback 到 manual
  │
  └─ HOLDINGS_PROVIDER=manual（始终可用）
       └─ get_holdings() → JsonStore 或空列表
```

> 注：当前降级由用户在设置页或持仓弹窗手动切换数据源实现，不会在读取失败时自动改用其他来源。
