# 券商持仓接入方案

> 代码入口：`adapter/holdings_providers/`，配置：`HOLDINGS_PROVIDER` 环境变量

## 方案对比

| | **manual** | **easytrader** | **qmt** | **joinquant** |
|---|---|---|---|---|
| **数据来源** | 用户手动录入 | 通达信/同花顺客户端（GUI 自动化） | miniQMT/xtquant（官方 Python API） | 聚宽 jqdatasdk |
| **真实持仓** | ✅（手动维护） | ✅（实时读取） | ✅（实时读取） | ❌（仅行情/财务数据） |
| **券商权限** | 无需 | 无需（只需安装客户端） | 需开通 QMT（通常 10 万门槛） | 需购买授权（~¥6999/年） |
| **稳定性** | ⭐⭐⭐⭐⭐ | ⭐⭐（UI 自动化，受客户端版本影响） | ⭐⭐⭐⭐⭐（官方 API） | ⭐⭐⭐⭐（数据 API 稳定） |
| **速度** | 即时 | 秒级（需操作 GUI） | 毫秒级（IPC 直连） | 秒级（网络请求） |
| **覆盖券商** | 任意 | 通达信/同花顺（几乎所有券商） | 60+ 家（华鑫、国金、中泰等） | 聚宽平台 |
| **平台** | 跨平台 | 仅 Windows | 仅 Windows | 跨平台 |
| **适合场景** | 临时/测试 | 快速验证，无券商门槛 | 生产环境长期使用 | 行情数据补充 |

## §manual — 手动录入

当前默认方案。用户通过 `POST /holdings/save` 或 dsh 对话维护持仓，落 `JsonStore`（`data/adapter/holdings.json`）。

**配置：**
```env
HOLDINGS_PROVIDER=manual
```

无需额外配置。

## §easytrader — CLI/GUI 自动化接入

通过 [easytrader](https://github.com/shidenggui/easytrader) + pywinauto 操控券商客户端窗口，读取持仓/资金/委托。

### 覆盖范围：按内核适配，覆盖贴牌券商

国内券商 PC 客户端大多是「贴牌」生态（采购同花顺/通达信内核定制），因此按内核适配一次即可覆盖一大批券商：

| 内核 | easytrader 模式 | 锚定程序 | 覆盖券商 |
|------|----------------|----------|---------|
| 同花顺 | `thstrader` | `xiadan.exe` | 80+ 家（平安/国金/银河/华泰/招商/中信建投…） |
| 通达信 | `tdxtrader` | `tdxw.exe` | 60+ 家（各家通达信定制版） |

全部券商档案见 `adapter/holdings_providers/broker_profiles.py` 注册表
（`THS_BROKERS` / `TDX_BROKERS`，遗漏的券商在表尾追加一行即可）。
CLI 随时可查：

```bash
env\Scripts\python.exe holdings_cli.py detect --list   # 列出全部支持券商
```

### 快速接入（推荐：自动发现）

```bash
# 1. 装依赖
env\Scripts\python.exe -m pip install easytrader pywinauto
# 2. 扫描本机已装券商客户端，自动识别券商并生成 .env 建议
env\Scripts\python.exe holdings_cli.py detect
# 3. 把建议配置粘进 .env，启动并登录券商客户端后自检
env\Scripts\python.exe holdings_cli.py check
```

### 前置条件

1. **Windows 系统**（pywinauto 依赖）
2. **券商客户端**：安装对应内核客户端（同花顺贴牌券商装其「同花顺版」）并登录；
   同花顺通用版内置 80+ 券商账号登录，装一个即可覆盖大多数券商
3. **Python 依赖**：
   ```bash
   pip install easytrader pywinauto
   ```

### 配置（.env，二选一）

```env
HOLDINGS_PROVIDER=easytrader
# 方式 A：按券商档案（推荐，detect 自动生成）
EASYTRADER_BROKER=pingan                 # 档案 id 见 detect --list
EASYTRADER_CLIENT_PATH=C:\平安证券\同花顺版\xiadan.exe
# 方式 B：按内核（不区分具体券商）
EASYTRADER_CLIENT_TYPE=thstrader         # thstrader(同花顺) | tdxtrader(通达信)
EASYTRADER_CLIENT_PATH=C:\同花顺\xiadan.exe
```

`EASYTRADER_BROKER` 优先于 `EASYTRADER_CLIENT_TYPE`；进程检测与报错文案按档案执行。

### 字段映射

| easytrader 返回字段 | HoldingItem 字段 | 转换说明 |
|---------------------|-----------------|----------|
| `证券代码` / `stock_code` | `ticker` | 截取前6位数字 |
| `股票余额` / `volume` | `quantity` | int → float |
| `成本价` / `avg_price` | `cost_price` | 直接映射 |

### 已知问题

- 客户端窗口**必须保持打开且已登录**，最小化或遮挡可能导致操作失败
- 券商客户端版本更新后，UI 控件定位可能失效，需更新 easytrader 配置
- 查询速度受 GUI 操作延迟影响（约 2-5 秒/次）
- 推荐 fork：[shidenggui/easytrader](https://github.com/shidenggui/easytrader)（社区持续维护）

### 降级

当 easytrader 不可用（客户端未启动/未登录）时，`is_available()` 返回 `False`，`get_holdings()` 抛 `ProviderUnavailable`。上层可 fallback 到 manual。

## §QMT — 迅投 miniQMT/xtquant 接入

通过 [xtquant](https://pypi.org/project/xtquant/) 连接 miniQMT 客户端进程，获取真实持仓/资金/委托。**推荐的生产级方案。**

### 前置条件

1. **券商开户** + **开通 QMT 权限**（部分券商需 10 万+ 资产门槛，华鑫证券门槛较低）
2. **miniQMT 客户端**：下载并登录（券商官网或 QMT 官网获取）
3. **Python 依赖**：
   ```bash
   pip install xtquant
   ```

### 配置

```env
HOLDINGS_PROVIDER=qmt
QMT_ACCOUNT_ID=你的资金账号
QMT_SESSION_ID=888888
```

### 字段映射

| xtquant 字段 | HoldingItem 字段 | 转换说明 |
|-------------|-----------------|----------|
| `stock_code` | `ticker` | `"600519.SH"` → `"600519"`（去后缀取6位数字） |
| `volume` | `quantity` | int → float |
| `avg_price` | `cost_price` | 直接映射 |

### 扩展能力

QMTProvider 额外提供 `get_asset()` 方法查询账户资金：

```python
provider = QMTProvider()
asset = provider.get_asset()
# {"total_asset": 1000000.0, "cash": 500000.0, "market_value": 500000.0, "frozen_cash": 0.0}
```

后续可扩展：
- `query_stock_orders()` — 查询当日委托
- `query_stock_trades()` — 查询当日成交
- 下单/撤单（需合规确认 + 风控层）

### 支持 QMT 的常见券商

| 券商 | 门槛 | 说明 |
|------|------|------|
| **华鑫证券** | 较低 | 推荐，miniQMT 开通门槛低 |
| **国金证券** | 中等 | QMT 支持较好 |
| **中泰证券** | 中等 | 同时支持原生 XTP 接口 |
| **华泰证券** | 较高 | 需 50 万+ |
| **东方财富** | 中等 | EMQuantAPI |

### 降级

当 QMT 不可用（xtquant 未安装 / miniQMT 未运行 / 账号未配置）时，`is_available()` 返回 `False`，`get_holdings()` 抛 `ProviderUnavailable`。

## §joinquant — 聚宽数据源

**聚宽不提供真实券商持仓**，仅提供行情/财务数据。设 `HOLDINGS_PROVIDER=joinquant` 会直接抛 `ProviderUnavailable`。

本 Provider 保留结构供未来扩展（如拉历史行情补充 L1 风险分析），不作为持仓数据源使用。

## 降级链

```
用户请求 → get_provider()
  │
  ├─ HOLDINGS_PROVIDER=qmt
  │    └─ is_available()?  → ✅ get_holdings()
  │                     → ❌ fallback 到 easytrader
  │
  ├─ HOLDINGS_PROVIDER=easytrader
  │    └─ is_available()?  → ✅ get_holdings()
  │                     → ❌ fallback 到 manual
  │
  └─ HOLDINGS_PROVIDER=manual（始终可用）
       └─ get_holdings() → JsonStore 或空列表
```

> 注：当前降级由用户手动切换 `HOLDINGS_PROVIDER` 实现。未来可增加自动降级逻辑。
