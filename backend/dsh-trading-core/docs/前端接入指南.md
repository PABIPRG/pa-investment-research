# 前端接入指南 —— Python Adapter 与 UI 对接

> 面向：接入 `dsh-trading-core` Python API 的前端或宿主团队。
> API、请求和 SSE 数据结构的唯一事实来源是 [API-接口文档.md](API-接口文档.md)。

适配器是无状态 HTTP + SSE 服务，默认地址为 `http://127.0.0.1:8000`。前端发起分析任务、订阅 `/analyze/{task_id}/stream`，并通过同步接口读写自选、持仓、风险偏好和简报。

可复用的 TypeScript 客户端源码位于 [frontend/packages/investment-research/stock-analysis/src/client.ts](../../../frontend/packages/investment-research/stock-analysis/src/client.ts)。该客户端属于 frontend workspace；后端不负责安装、验证或启动它。

## 接入边界

```text
UI or host
  -> HTTP/SSE client
  -> Python adapter (127.0.0.1:8000)
  -> tradingagents engine
```

客户端应负责：请求序列化、SSE 帧解析、超时和取消、以及将 `stage`、`result`、`error`、`done` 映射为 UI 状态。后端负责任务生命周期、引擎执行和 API 契约；UI 不应复制业务计算或解析引擎报告。

## 本地联调（当前阶段）

```sh
cd backend/dsh-trading-core
./init.sh
ADAPTER_RUNNER=fake ./start.sh
curl http://127.0.0.1:8000/health
```

`fake` 运行器用于确定性联调，不调用 LLM 或行情服务；`engine` 是默认运行器。当前阶段只需启动 Python API。
