# 前端接入指南 —— industry-chain 产业链图谱适配器与 UI 对接

> 面向：接入 `industry-chain` Python API 的前端或宿主团队。
> API、请求和响应数据结构的唯一事实来源是 [API-接口文档.md](API-接口文档.md)。

产业链适配器是**同步只读 HTTP** 服务，默认地址为 `http://127.0.0.1:8200`。图谱数据懒加载自 `data/seed/`，查询全部走内存，秒级返回：前端发起 GET → 直接拿到结构化图谱数据渲染。无写操作、无任务式接口、无 SSE。

## 接入边界

```text
UI or host
  -> HTTP client
  -> industry-chain adapter (127.0.0.1:8200)
  -> data/seed/ 静态种子数据（懒加载入内存）
```

客户端应负责：请求序列化、超时与取消、坐标归一化、节点/边画布渲染。后端负责图谱查询、服务端切片过滤、实体解析与研报 overlay 合并；UI 不应复制 BFS 展开、社区归集或权重排序逻辑。

## 本地联调（当前阶段）

```sh
cd backend/industry-chain
# 首次：下载种子数据（约几十 MB，需能访问 github.io）
python scripts/fetch_seed_data.py          # 或跑 init.sh
python -m uvicorn industry_chain.app:app --port 8200
curl http://127.0.0.1:8200/health
curl http://127.0.0.1:8200/companies?keyword=电池&limit=5
curl "http://127.0.0.1:8200/graph/network?min_degree=3&subject_only=1" -o net.json
```

关键 `.env` 配置（前缀 `IC_`）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `IC_HOST` / `IC_PORT` | `127.0.0.1` / `8200` | 监听地址 |
| `IC_DATA_DIR` | `industry-chain/data/seed` | 种子数据目录。首次未下载时所有查询端点返回 503 |
| `IC_SEED_BASE_URL` | `https://villadora.github.io/iducsite/data` | 种子下载源 |
| `IC_DEEPSEEK_API_KEY` | 空 | 仅研报管线需要；纯图谱查询不依赖 LLM |

**无任何配置即可联调**：图谱查询是纯内存计算，不碰 LLM / 外部行情 / 网络（除首次下载种子数据外）。

## 前端用法（当前 product/ 前端为准）

### 渲染要点

- **全图网络**（`#/chain`）：`/graph/network` 返回的节点已带 `init_x` / `init_y`（普通模式为原始坐标域、全 A 股模式已归一化到 `[50,2350]×[50,1550]`）。前端按需二次归一化或直接用；边用 `kind`（supplier/customer）分方向、`share` 控线宽、`type="inferred"` 画虚线、`confidence` 分级显示。
- **社区侧栏**：`macro_communities` 按 `macroId` 分组，`industry` 字段为社区成员 A 股的主导申万行业，可作分组标签。
- **单公司视图**：`/graph/single/{code}` 是列式数据（供应商 → 原材料 → 核心公司 → 主营产品 → 下游客户），前端画 SVG 边；供应商/客户经多材料/产品出现时后端已合并并给 `vias`。
- **多层展开**：`/graph/chain/{code}` 按 `up_levels`（level 为负）/ `down_levels`（level 为正）分层渲染，`node.parent_id` 指回父层，`depth` 是距中心层数。
- **名称→code 解析**：用 `/companies?keyword=…&limit=1`；结果空则说明该公司不在图谱（可再试 `/graph/entity/名称` 走全 A 股兜底）。
- **实体点击**：`/graph/entity/{key}` 统一处理三种实体（核心公司 / 非核心实体 / A 股兜底），`is_subject` 区分层级，`source="a_share_universe"` 标注兜底档案。

### 性能注意

- `/graph/network` **不要带大 limit 全量拉**——服务端切片参数（`min_degree` / `min_market_cap` / `min_share` / `subject_only`）就是给前端减负的；全 A 股模式 `include_universe=1` 一次返回 5901 节点，仅切换视图时调用，不要轮询。
- 图谱查询全部秒级，但首次访问会触发种子数据懒加载（~10-15MB JSON 读盘 + 建索引，可能 1-3s），可接受；之后全内存。
- 数据变更（重新跑研报管线 / 更新种子）后需**重启适配器**让缓存失效，无热更端点。
